```

```
To:
```
px-3 py-2.5 sm:py-1 rounded text-sm font-medium transition-colors cursor-pointer active:scale-95 transition-transform min-h-[44px]
```

- `active:scale-95 transition-transform`: tap feedback animation (MOB-TOUCH-03)

Note: `transition-colors` is already present. Tailwind v4 handles multiple transition properties — `transition-transform` will add transform to the transition. If this causes issues, replace both with `transition-all`. Test by building.
