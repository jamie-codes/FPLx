## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-127-06 | Tampering | localStorage `fplx_watchlist` value | accept | Personal-tool / per-device state with no security boundary (CONTEXT.md research §Security Domain). loadWatchlist filters non-number entries; downstream consumers (Plan 03 WatchlistTab) treat IDs as a filter set against the validated `/api/players` response. |
| T-127-07 | Input Validation | Malformed JSON in localStorage | mitigate | try/catch around JSON.parse + Array.isArray + typeof number filter in `loadWatchlist`; returns [] on any failure. Verified by the malformed-json test case. |
| T-127-08 | Denial of Service | Unbounded watchlist size | accept | RESEARCH.md OOS section caps assumed at 20-40 pinned players; virtualisation deferred. No throttling needed for this scale. |
| T-127-09 | Spoofing | Star-button click events on a row's player id | accept | `row.original.id` comes from the already-trusted `/api/players` response — same trust boundary as the rest of GemTable. |
</threat_model>
