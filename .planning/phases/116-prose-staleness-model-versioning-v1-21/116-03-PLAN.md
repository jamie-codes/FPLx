<objective>
Add `sample_gws` to the accuracy.py version record schema and extend the TypeScript `VersionRecord` interface so the v1.21 UI (Plan 04) can label cold-start version entries (CONTEXT.md D-09..D-11, VER-01).

Purpose: Without a sample size on each version record, the existing UI shows misleading 0.0% hit rates for versions that have not yet accumulated finished gameweeks. Adding `sample_gws` lets the UI distinguish cold-start from real regressions.
Output: Modified `pipeline/accuracy.py` (two write sites: `new_version_record` and `_empty_backtest`), extended `pipeline/tests/test_accuracy.py`, and extended `src/lib/types.ts`.

This plan is intentionally Wave 1 (independent of Plan 04 in terms of file ownership) — its output is what Plan 04 will consume in Wave 2.
</objective>
