## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FPL API merged player data → prose prompt | `p.get('news')`, `p.get('chance_of_playing_next_round')` from FPL bootstrap-static. Untrusted strings injected into LLM prompt. |
| Prompt builder → Claude API | User prompt is sent to the Anthropic API; content includes player names, team short names, and FPL news strings. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-116-02-01 | Injection | `news` field embedded in XML attribute | mitigate | Replace `"` with `'` in `news` value before embedding in attribute (`news.replace('"', "'")`); XML structure validity preserved; downstream `_passes_guardrail` rejects names not in player_corpus, preventing LLM hallucinations from being saved |
| T-116-02-02 | Information Disclosure | LLM prompt content | accept | Prompt contains FPL public data (player names, team short names, public news). No PII, no API keys, no secrets. Anthropic API is the documented downstream consumer per Phase 67. |
| T-116-02-03 | Tampering | `chance_of_playing_next_round` integer field | mitigate | Field is cast and bounds-checked via `< 100` predicate; non-int / None values are skipped without emitting the attribute |
| T-116-02-04 | Denial of Service | `dgw_teams` length unbounded | accept | At most 20 PL teams; a worst-case 20-team DGW (impossible in practice — max ~12) adds ~200 bytes to the prompt. No DoS surface. |
| T-116-02-05 | Tampering | `_detect_dgw_bgw` return mapping | mitigate | run.py only consumes entries where `kind == 'dgw'` and filters out empty `team_short_name`; unexpected entries cannot inject content into the prompt |
| T-116-02-06 | Spoofing | N/A | accept | No authentication boundary in this plan; ANTHROPIC_API_KEY check in `generate_weekly_summary` is unchanged |
| T-116-02-07 | Repudiation | N/A | accept | LLM call already wrapped in `try/except` with stderr logging (line 402); no new repudiation surface |
| T-116-02-08 | Elevation of Privilege | `_detect_dgw_bgw` import inside try block | accept | Function is read-only on `merged`; no privilege escalation possible from a pure transform |
