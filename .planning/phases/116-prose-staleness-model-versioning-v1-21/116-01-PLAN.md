## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-116-01-01 | Tampering | `ProseSummaryBlock.generated_at` | mitigate | `new Date(generated_at).getTime()` is checked via `Number.isFinite()`; non-finite (NaN) values fall back to the static `Updated GW{N}` label without throwing or rendering an "Invalid Date" string |
| T-116-01-02 | Information Disclosure | Footer text | accept | Footer renders only `Updated X ago · GW{N}` — no user PII, no auth tokens, no server paths. Low value, no exposure risk. |
| T-116-01-03 | Denial of Service | Future-dated `generated_at` | accept | A future timestamp yields negative `minutesAgo` so `isStale` is false (renders fresh). No crash, no infinite loop. Worst case: displays "X min ago" with a negative number, which is cosmetic only. |
| T-116-01-04 | Elevation of Privilege | `displayed.generated_at` rendered as text | mitigate | React's default escaping handles XSS — `generated_at` is rendered as a child string, never as `dangerouslySetInnerHTML`. No additional sanitisation required. |
| T-116-01-05 | Spoofing | N/A | accept | No authentication boundary crossed in this component. |
| T-116-01-06 | Repudiation | N/A | accept | No state mutation in this plan. |
