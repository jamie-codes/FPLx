4. Cache the result to `pipeline/cache/understat_current.json` with a `_cached_at` ISO timestamp.
5. Return the dict.

**merge.py:**
Create `pipeline/merge.py` with function `merge_players(bootstrap: dict, fixtures: list, understat: dict, id_map: dict) -> list[dict]` that:

1. **Build team lookup:** `teams = {t['id']: t for t in bootstrap['teams']}` and `events = bootstrap['events']`.

2. **Determine current GW:** Find the event where `is_current == True`. If none, use the last finished event. Store as `current_gw: int`.

3. **Compute rolling xGA per team (D-02):** From `fixtures` list, filter to finished fixtures (`finished == True`). For each team, collect the last 6 completed fixtures. For each fixture, the team's xGA is derived from the opponent's goals scored (use `team_h_score` / `team_a_score` as proxy since FPL fixtures don't have xGA — see note below). Compute `rolling_xga = sum(goals_conceded_last_6) / 6` per team. Store as `team_xga: dict[int, float]`.

   **Important note on xGA source:** The FPL fixtures endpoint does not include xGA. Use actual goals conceded from finished fixtures as the proxy (`team_a_score` when team is home, `team_h_score` when team is away). This is the best available without a separate Understat team-level fetch. The rolling 6-game window per D-02 smooths noise.

4. **Compute difficulty tiers (D-05):** From `team_xga` values, compute percentile thresholds. Sort all 20 team xGA values. Bottom third (lowest xGA = hardest to score against) = "hard". Top third (highest xGA = easiest to score against) = "easy". Middle third = "medium". Store thresholds as `easy_threshold` and `hard_threshold`. Also normalise each team's xGA to a 0.0-1.0 `difficulty_score` float: `score = 1.0 - (team_xga - min_xga) / (max_xga - min_xga)`. So 0.0 = easiest fixture, 1.0 = hardest.

5. **Build upcoming fixtures per player (D-03, D-04):** From `fixtures`, filter to unfinished fixtures (`finished == False`), sorted by `event` (GW number). For each player's team, collect the next 5 fixtures. Each fixture entry:
   ```python
   {
     "opponent_team": teams[opponent_id]['short_name'],  # e.g. "ARS"
     "is_home": bool,  # True if player's team is the home team
     "event_id": fixture['event'],  # GW number
     "difficulty_score": difficulty_scores[opponent_id],  # 0.0-1.0 float
     "difficulty_tier": "easy" | "medium" | "hard"  # from percentile thresholds
   }
   ```

6. **Compute per-90 form metrics (D-01):** For each player element from `bootstrap['elements']`:
   - `total_points` and `minutes` are season totals from bootstrap. For the form window (last 5 GWs), use `form` field (FPL's own last-5-GW form string) converted to float as `form_pts_per90`. For season-level per-90: `minutes_per90 = minutes / max(starts, 1)` (average minutes per start).
   - **Note:** True per-GW granular form requires element-summary (Phase 4). For Phase 2, use the FPL `form` field (already a per-game average over recent GWs) as `form_pts_per90`, and compute `xg_per90` and `xa_per90` from Understat season totals: `xg_per90 = (xG / minutes) * 90` if minutes > 0, else null.

7. **Merge into output list (D-06):** For each player in `bootstrap['elements']`:
   ```python
   {
     # All Phase 1 FPL fields
     "id": element['id'],
     "web_name": element['web_name'],
     "team": element['team'],
     "team_short_name": teams[element['team']]['short_name'],
     "element_type": element['element_type'],
     "now_cost": element['now_cost'],
     "selected_by_percent": element['selected_by_percent'],
     "form": element['form'],
     "status": element['status'],
     "minutes": element['minutes'],
     "starts": element['starts'],
     "total_points": element['total_points'],
     "defensive_contributions": element.get('defensive_contributions'),
     "clearances_blocks_interceptions": element.get('clearances_blocks_interceptions'),
     "direct_freekicks_order": element.get('direct_freekicks_order'),
     "penalties_order": element.get('penalties_order'),
     "corners_and_indirect_freekicks_order": element.get('corners_and_indirect_freekicks_order'),
     "news": element['news'],
     # Understat fields (null for unmatched per Pitfall 12)
     "understat_id": id_entry.get('understat_id') if id_entry else None,
     "xg_per90": computed or None,
     "xa_per90": computed or None,
     # Form fields (D-01)
     "minutes_per90": computed,
     "form_pts_per90": float(element['form']),
     # Fixtures (D-03)
     "fixtures": [next 5 fixture dicts],
   }
   ```
   Where `id_entry = id_map.get(str(element['id']))`.
   For unmatched players (no understat_id or understat_id is None): set `xg_per90` and `xa_per90` to `None` (NOT zero, per Pitfall 12 and Phase 1 D-02).
