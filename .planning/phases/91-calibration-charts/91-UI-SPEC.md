## Chart Specification: xPts-Mean Calibration Chart

### Layout

- Stacked below the existing haul-rate chart inside `CalibrationSection`.
- Vertical gap between charts: `mt-12` (48px) matching the 2xl spacing token.
- `PositionTabSelector` renders once, above both charts. Single `position` state drives both via `useMemo` on the same `data.calibration?.by_position?.[position]` guard.

### Dimensions

- `ResponsiveContainer width="100%" height={288}` — identical to existing chart.
- Chart container: `rounded border border-zinc-200 dark:border-zinc-700 bg-zinc-50 dark:bg-zinc-800 px-2 py-3 relative` — identical class string to existing chart.

### Axes

| Axis | dataKey | Type | Domain | Tick format |
|------|---------|------|--------|-------------|
| XAxis | `predicted_mean` | `type="number"` (REQUIRED — Pitfall 4) | auto (recharts default) | `{v.toFixed(1)}` — 1dp float pts |
| YAxis | `actual_mean` | `type="number"` | auto | `{v.toFixed(1)}` — 1dp float pts |

- Both axes: `tick={{ fontSize: 12, fill: 'currentColor' }}`, `axisLine={false}`, `tickLine={false}`.
- YAxis `width={40}`.
- No hardcoded domain — auto-scaled from data values (predicted xPts range, e.g. 1.5–8.0).

### Reference Line (y = x diagonal)

```
<ReferenceLine
  segment={[{ x: 0, y: 0 }, { x: maxPredictedMean, y: maxPredictedMean }]}
  stroke="rgba(161,161,170,0.5)"
  strokeDasharray="4 4"
  strokeWidth={1}
  ifOverflow="extendDomain"
/>
```

- `maxPredictedMean` derived from chart data: `Math.max(...xptsData.map(b => b.predicted_mean ?? 0))` — computed in `useMemo` alongside the filtered data.
- If `xptsData` is empty, `maxPredictedMean` defaults to `1` (prevents NaN segment).

### Data Line

```
<Line
  type="monotone"
  dataKey="actual_mean"
  stroke="currentColor"
  strokeWidth={2}
  dot={{ r: 3, fill: 'currentColor' }}
  activeDot={{ r: 5 }}
  connectNulls={false}
  isAnimationActive={false}
/>
```

> Source: Identical to existing `actual_rate` line at `AccuracyTab.tsx:336–345`. Pattern is locked from Phase 63.

### Sparse-bucket Filter

Applied at the component edge in `useMemo`:
```ts
const xptsData = useMemo<CalibrationBucket[]>(() => {
  const all = data.calibration?.by_position?.[position] ?? []
  return all.filter((b) => b.sample_n >= 5 && b.predicted_mean != null && b.actual_mean != null)
}, [data.calibration, position])
```

> Source: CONTEXT.md D-06; ROADMAP §Phase 91 SC-4. Filters both sparse buckets AND buckets missing the new optional fields (backward-compat with Phase 63 caches).

## Copywriting Contract

| Element | Copy |
|---------|------|
| New chart section heading | `Predicted vs Actual xPts` |
| New chart description | `Predicted xPts decile mean vs actual points mean. A well-calibrated model traces the diagonal — points above mean over-prediction, points below mean under-prediction.` |
| Empty state (insufficient sample) | `Insufficient sample (n<5) for {positionLabel(position)} this window.` |
| Tooltip header | `Decile {bucketLow}%–{bucketHigh}%` (same format as CalibrationTooltip) |
| Tooltip predicted row | `Predicted: {p.predicted_mean?.toFixed(2)} pts` |
| Tooltip actual row | `Actual: {p.actual_mean?.toFixed(2)} pts` |
| Tooltip deviation row | `Deviation: {((p.actual_mean ?? 0) - (p.predicted_mean ?? 0)).toFixed(2)} pts` |
| Tooltip sample row | `n = {p.sample_n}` |
| Primary CTA | None — this phase has no CTA buttons; it is a read-only visualization. |
| Destructive confirmation | None — no destructive actions in this phase. |

> Source: CONTEXT.md "Claude's Discretion" — tooltip format; `positionLabel()` at `AccuracyTab.tsx:211`; empty state pattern from existing chart at `AccuracyTab.tsx:349–354`.

Deviation sign convention: positive = model over-predicts (player scored less than predicted); negative = model under-predicts. This matches "points above diagonal = over-prediction" description in CONTEXT.md D-04.

## Interaction Contract

| Interaction | Behaviour |
|-------------|-----------|
| PositionTabSelector pill click | Updates single `position` state; both charts re-render via `useMemo` — no fetch, no loading state |
| Chart dot hover | Shows `XptsTooltip` with 4 fields: predicted, actual, deviation, sample n |
