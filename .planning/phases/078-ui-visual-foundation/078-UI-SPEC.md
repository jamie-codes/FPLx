## Token System

All tokens are defined in `src/app/globals.css` via the Tailwind v4 `@theme inline` block.
Pattern: CSS custom property in `:root`/`.dark` → `@theme inline` entry → first-class Tailwind utility class.

### Complete Token Set (VIS-01)

| CSS Custom Property | Light Value | Dark Value | Tailwind Utility Class |
|---------------------|-------------|------------|------------------------|
| `--background` | `#F7F8FC` | `#0a0a0a` | `bg-background` |
| `--surface` | `#ffffff` | `#111827` | `bg-surface` |
| `--surface-elevated` | `#f3f4f6` | `#1f2937` | `bg-surface-elevated` |
| `--foreground` | `#171717` | `#ededed` | `text-foreground` |
| `--muted` | `#6b7280` | `#9ca3af` | `text-muted` |
| `--border` | `#e5e7eb` | `#374151` | `border-border` |
| `--color-primary` | `#22c55e` | `#22c55e` | `text-primary` / `bg-primary` |
| `--color-secondary` | `#3b82f6` | `#3b82f6` | `text-secondary` / `bg-secondary` |
| `--color-positive` | `#22c55e` | `#22c55e` | `text-positive` / `bg-positive` |
| `--color-warning` | `#f59e0b` | `#f59e0b` | `text-warning` / `bg-warning` |
| `--color-negative` | `#ef4444` | `#ef4444` | `text-negative` / `bg-negative` |

**Source:** D-01, D-03, D-12 (CONTEXT.md)

**`@theme inline` wiring pattern** (mirrors existing `--font-geist-sans` → `--font-sans`):
```css
@theme inline {
  --color-background: var(--background);
  --color-surface: var(--surface);
  --color-surface-elevated: var(--surface-elevated);
  --color-foreground: var(--foreground);
  --color-muted: var(--muted);
  --color-border: var(--border);
  --color-primary: var(--color-primary);
  --color-secondary: var(--color-secondary);
  --color-positive: var(--color-positive);
  --color-warning: var(--color-warning);
  --color-negative: var(--color-negative);
}
```

**Sticky nav opacity variant:** Use `bg-surface/95` opacity shorthand (D-08). Do NOT create a separate `--surface-sticky` token — Tailwind v4 handles opacity modifiers natively.

**Token scope this phase:** `page.tsx`, `MobileNav.tsx`, `globals.css` only. Tab content components (InsightsTab, GemTable, DefCon, etc.) retain existing `zinc-*` classes — follow-on phase migrates those. (D-02)

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, dot indicator gap in badge |
| sm | 8px | Pill badge padding horizontal (`px-2` = 8px) |
| md | 16px | Section padding, nav row horizontal padding |
| lg | 24px | Content spacing below sticky nav |
| xl | 32px | Major content block gaps |
| 2xl | 48px | Page-level section breaks |
| 3xl | 64px | Not used in this phase |

**Exceptions:**
- Pill badge vertical padding: `py-0.5` (2px) — deliberate sub-scale value for inline badge height control (D-10)
- Touch target minimum: `min-h-[44px]` on all interactive nav buttons — enforced on pill nav buttons per established pattern in MobileNav (D-05, existing MobileNav line ~40)

**Pill nav row gaps:** `gap-2` (8px) between pill items within a nav row.

## Typography

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Geist Sans | Default content text |
| Label | 12px (text-xs) | 500 (medium) | 1.4 | Geist Sans | Pill nav labels, badge text |
| Nav pill | 14px (text-sm) | 500 (medium) | 1 | Geist Sans | Section tab + sub-tab buttons |
| Display | 48px (text-5xl) | — (Honk var) | 1 (leading-none) | Honk | FPLx logo only — untouched |

**Font removal:** Delete `font-family: Arial, Helvetica, sans-serif` from the `body` rule in `globals.css` (line 30). After removal, `body` inherits Geist Sans via `--font-sans` mapped in `@theme inline`. (VIS-02)

**Tabular numerics:** Apply `font-variant-numeric: tabular-nums` as a **global CSS rule** in `globals.css` targeting numeric data elements. Selector: `.tabular-nums, [data-numeric]`. Reason: a single CSS rule is simpler to maintain than a per-component Tailwind utility; avoids drift when new data columns are added. (Claude's Discretion)

### LastUpdated Badge (VIS-04, D-09, D-10, D-11)

**Location:** Moved from `page.tsx` header div to the sticky section-tabs nav row, right side. Use `ml-auto` in the section tabs flex row.

**Render contract for `LastUpdatedDisplay`:**

Normal state:
```
<span class="inline-flex items-center gap-1 rounded-full px-2 py-0.5 text-xs bg-surface-elevated text-muted">
  <span aria-hidden="true">●</span>
  Updated {relativeTime}
</span>
```

Stale state (`stale === true`):
```
<span class="inline-flex items-center gap-1 rounded-full px-2 py-0.5 text-xs bg-amber-50 text-amber-600 dark:bg-amber-950 dark:text-amber-400">

  Updated {relativeTime}
```

**Stale threshold:** >2h (already in `useLastUpdated` hook — stale flag comes from API response). Do NOT change the hook logic.

**`<p>` tag removed:** Current markup wraps in `<p class="text-xs mt-1">`. Replace with `<span>` for inline-in-nav use. Update `LastUpdated.test.tsx` to match new element type and classes.

## Interaction States

| Component | Default | Hover | Active/Selected | Focus |
|-----------|---------|-------|-----------------|-------|
| Section tab pill | Transparent bg, `text-muted` | `text-foreground` | `bg-zinc-900 text-white` (light) / `bg-white text-zinc-900` (dark) | `focus-visible:ring-2 focus-visible:ring-offset-1` |
| Sub-tab pill | Transparent bg, `text-muted` | `text-foreground` | Same as section tab | Same |
| MobileNav sub-tab pill | Transparent bg, `text-zinc-400` | `text-zinc-200` | `bg-zinc-900 text-white` | Implicit (mobile) |
| Freshness badge | Normal pill | No hover (non-interactive) | Not applicable | Not applicable |

**Touch targets:** All nav buttons enforce `min-h-[44px]`. Sub-tab pills that are visually shorter must use `min-h-[44px]` with `items-center` to pad to tap target size without expanding visible pill height.

**Transition:** `transition-colors` on all pill buttons. Duration: Tailwind default (150ms).

## Accessibility

- Section tabs: `aria-label="Section navigation"` on `<nav>`, `aria-current="page"` on active button (already present — retain)
- Sub-tab nav: `aria-label="{SectionLabel} sub-tabs"` on `<nav>`, `aria-current="page"` on active (already present — retain)
- Freshness badge dot (`●`, `⚠`): `aria-hidden="true"` — text already communicates state
- Sticky nav `z-40`: does not overlap modals (modals use higher z-index)
- Color contrast: `text-zinc-900` on `bg-white` = 21:1 (AAA). `text-zinc-500` on `#F7F8FC` = ≥4.5:1 (AA). `text-amber-600` on `bg-amber-50` ≥ 4.5:1 (AA).
