## Component Inventory

New components for this phase:

### 1. Status Pill Row

Location: top of `NextSeasonPlannerTab` return, before the "Pre-Season Squad" section heading.

```
<div className="flex items-center gap-2 py-2">
  {isActive
    ? <span className="text-xs font-normal text-green-800 dark:text-green-200 bg-green-100 dark:bg-green-900 rounded px-2 py-1">Live</span>
    : <span className="text-xs font-normal text-zinc-600 dark:text-zinc-300 bg-zinc-100 dark:bg-zinc-800 rounded px-2 py-1">Awaiting</span>
  }
</div>
```

States:
- Loading (hook not yet resolved): render nothing — avoids flash of wrong state.
- Awaiting (`data === null`): zinc pill with text "Awaiting".
- Live (`data !== null`): green pill with text "Live".

Pill text is one word each — no icon, no supplementary text inline with the pill.

Source: CONTEXT.md D-09 ("standalone status row, first element inside NextSeasonPlannerTab"), D-10 ("one word each, no icon needed"), D-11.

### 2. First-Activation Banner

Location: between the status pill row and the `<h3>Pre-Season Squad</h3>` heading. Renders only when active AND localStorage key absent.

```
<div className="rounded border border-green-400 bg-green-50 dark:bg-green-950 p-4 text-sm text-green-800 dark:text-green-200 mb-4 flex items-start justify-between">
  <span>🏆 Pre-season is live — your squad has been re-optimised against the new FPL prices.</span>
  <button
    onClick={onDismiss}
    className="ml-4 text-green-600 dark:text-green-400 hover:text-green-800 dark:hover:text-green-200 min-h-[44px] min-w-[44px] flex items-center justify-center"
    aria-label="Dismiss activation banner"
  >
    ×
  </button>
</div>
```

States:
- Shown: `isActive && !dismissed`
- Hidden: `!isActive || dismissed`

Dismiss behaviour: `localStorage.setItem('nsp_activation_seen_' + seasonId, 'true')` then local `setDismissed(true)`. Banner never returns after dismiss.

Source: CONTEXT.md D-12 ("inline in tab flow, not a toast"), D-13, D-14, D-15. Banner color pattern mirrors `SetPieceChangeAlert.tsx` (amber → green semantic swap).

## Interaction Contract

### usePreSeasonActive() Hook

- TanStack Query, `staleTime: 60_000` ms (same as `usePreSeasonSquad`).
- Returns `PreSeasonActiveResponse | null`. `null` = 404 = Awaiting.
- On non-404 error: log and return `null` (treat as Awaiting — user does not see error).

### Banner Dismiss Flow

1. User clicks × button.
2. `localStorage.setItem('nsp_activation_seen_' + data.season_id, 'true')` executes synchronously.
3. Local state `dismissed` → `true`.
4. Banner unmounts. Does not re-appear for this season.

### localStorage Key Pattern

Key: `nsp_activation_seen_{seasonId}` where `seasonId` comes from `data.season_id` (e.g. `"2526"`).

Note: this deviates from the project's `fplx_` prefix pattern. CONTEXT.md §code_context flags this for planner to confirm or align. The UI-SPEC locks the key format from CONTEXT.md D-13/D-15 (`nsp_activation_seen_{seasonId}`); alignment to `fplx_nsp_activation_seen_{seasonId}` is acceptable if the planner standardises it — either key is valid as this is a fresh key with no existing data.
