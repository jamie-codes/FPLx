```
<button
  aria-label="Push notifications"
  aria-expanded={open}
  aria-haspopup="dialog"
  className="p-2 rounded text-zinc-500 hover:text-zinc-900 dark:text-zinc-400 dark:hover:text-white min-h-[44px]"
>
  🔔
</button>
```

- Placed in both header clusters: `src/app/page.tsx` lines 197–199 (scroll-away header) AND lines 217–220 (sticky nav `ml-auto` cluster), immediately adjacent to `<ThemeToggle />`.
- Uses the bell emoji `🔔` as the icon — consistent with emoji-literal pattern in ThemeToggle (sun/moon).
- `aria-expanded` reflects popover open state; `aria-haspopup="dialog"` signals the popover role to screen readers.

### NotificationPopover (new)

A native HTML `<dialog>` element positioned as a popover below the bell button.

```
<dialog
  aria-label="Push notification settings"
  className="absolute top-full right-0 mt-2 w-60 bg-surface border border-border rounded-lg p-4 shadow-lg z-50"
>
  {/* Toggle row */}
  <div className="flex items-center justify-between gap-4">
    <span className="text-sm font-medium text-foreground">Push notifications</span>
    <button
      role="switch"
      aria-checked={subscribed}
      className="..."
    >
      {/* toggle thumb */}
    </button>
  </div>

  {/* Status line */}
  <p className="mt-2 text-sm text-muted">
    {statusText}
  </p>
</dialog>
```

Popover dimensions: `w-60` (240px fixed width), auto height.
Border: `border border-border` — uses existing `--border` token.
Shadow: `shadow-lg` (Tailwind default large shadow).
Close-on-outside-click: handled by listening to `click` events on `document` in the parent client component.

### Push toggle (within NotificationPopover)

Visual toggle switch (not a native `<input type="checkbox">`) implemented as a `<button role="switch">`.

States:
- Off (not subscribed): track `bg-zinc-200 dark:bg-zinc-700`, thumb `bg-white`.
- On (subscribed): track `bg-primary` (#22c55e), thumb `bg-white`.
- Disabled (permission denied): track `bg-zinc-100 dark:bg-zinc-800 opacity-50`, interaction blocked.

Dimensions: track `w-10 h-6` (40px x 24px), thumb `w-4 h-4` (16px x 16px). Thumb translates `translate-x-1` (off) to `translate-x-5` (on).

### Status line text (within NotificationPopover)

Single `<p>` below the toggle row. Three variants:

| State | Text | Colour class |
|-------|------|--------------|
| Subscribed | "You're subscribed to push notifications" | `text-green-600 dark:text-green-400` |
| Permission denied | "Notifications blocked — check browser settings" | `text-amber-600 dark:text-amber-400` |
| Not subscribed | "Enable to receive price and deadline alerts" | `text-muted` |

## Interaction Contract

### Bell button click
1. Opens NotificationPopover below the bell button.
2. Does NOT trigger browser permission prompt — that fires only when user explicitly clicks Enable toggle for the first time.
3. Second click on bell (or click outside popover) closes the popover.

### Enable toggle — first click (no prior permission)
1. Toggle animates to "on" optimistically.
2. Browser permission prompt fires.
3. If granted: call `POST /api/push/subscribe` with the subscription object. Status line transitions to "Subscribed".
4. If denied: revert toggle to off. Status line transitions to "Notifications blocked — check browser settings". Toggle is visually disabled.

### Enable toggle — subsequent enable (permission already granted)
1. Toggle animates to "on".
2. Call `POST /api/push/subscribe` directly (no prompt). Status line transitions to "Subscribed".

### Disable toggle
1. Toggle animates to "off".
2. Call `DELETE /api/push/subscribe` (or POST with unsubscribe flag).
3. Status line transitions to "Enable to receive price and deadline alerts".

### Notification received (service worker)
- Service worker at `public/sw.js` handles `push` events — renders OS-level notification.
- No in-app UI change is triggered by receiving a push notification (no inbox, no badge in this phase).
- Notification click: opens the app URL (or a deep link if provided in payload).

## Accessibility Contract

- Bell button: `aria-label="Push notifications"`, `aria-expanded`, `aria-haspopup="dialog"`.
- Toggle: `role="switch"`, `aria-checked={subscribed}`, `aria-label="Enable push notifications"`.
- Status line: `aria-live="polite"` — announces status transitions to screen readers without interrupting.
- Popover: `aria-label="Push notification settings"`, closes on Escape key.
- All interactive elements: `min-h-[44px]` touch target (WCAG 2.5.5).
- Focus management: when popover opens, focus moves to the toggle. When popover closes, focus returns to bell button.
