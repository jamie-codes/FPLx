# Phase 75 — UI Design Contract

> Visual and interaction contract for `FixtureHeatMap` v2. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase extends an existing component within an established design language. The contract below codifies the conventions already in use across `FixtureHeatMap`, `AttDefToggle`, `GwToggle`, and `ThemeToggle` so the planner/executor stay consistent. No new tokens, no new colours, no new fonts.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Tailwind v4 utility-first; no `components.json` in repo) |
| Preset | not applicable |
| Component library | none (in-repo primitives in `src/components/`); `@custom-variant dark (&:where(.dark, .dark *))` declared in `src/app/globals.css:3` |
| Icon library | none required for this phase (text-only labels and pill controls) |
| Font | Geist Sans (`--font-geist-sans` body) + Geist Mono (`--font-geist-mono` table cells, GW labels, opponent abbreviations) — declared in `src/app/globals.css:15-19` |

**Detection notes:**
- No `components.json`; no `tailwind.config.*` (Tailwind v4 uses CSS-first `@theme`).
- Class-based dark mode via `.dark` on `<html>`; canonical detection is `document.documentElement.classList.contains('dark')` per `src/components/theme/ThemeToggle.tsx:9`.
- Inline-style gradient cells require JS-side dark detection (Tailwind `dark:` variant cannot reach inline `style`). RESEARCH §Pattern 2 mandates `MutationObserver` on `<html>.classList` for live theme reactivity.

## Color

The app uses Tailwind v4 default neutrals (`zinc-*`) for chrome and a 3-tier semantic palette (green / amber / red) for fixture difficulty. The 60/30/10 split below describes the **heat map view specifically**, not the global app.

**Primary visual anchor: the heat-map grid cells, encoded by tier color (green/amber/red).**

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) — Surface light | `bg-white` (`#ffffff`) | Page surface beneath the table; controls bar buttons in unselected state |
| Dominant (60%) — Surface dark | `bg-zinc-900` family (`#18181b`) | Same role under `.dark` |
| Secondary (30%) — Chrome light | `border-zinc-200` (`#e4e4e7`), `border-zinc-300` (`#d4d4d8`), `bg-zinc-50` (`#fafafa`) | Table borders, BGW empty cells, control-group borders, row dividers (`border-b border-zinc-100`) |
| Secondary (30%) — Chrome dark | `border-zinc-700`/`border-zinc-600`, `bg-zinc-900`, `bg-zinc-800` | Same role under `.dark` |
| Tier — Easy (semantic, ~3%) | Light: `bg-green-100` `#dcfce7` (text `text-green-800`) · Dark: `bg-green-900` (text `text-green-200`) · Gradient HEX dark: `#14532d` | Fixture cell where `tier()` returns `'easy'` (att ≤ 0.4 or `defensive_difficulty` ≤ 0.4 in DEF mode) |
| Tier — Medium (semantic, ~3%) | Light: `bg-amber-100` `#fef3c7` (text `text-amber-800`) · Dark: `bg-amber-900` (text `text-amber-200`) · Gradient HEX dark: `#78350f` | Fixture cell where `tier()` returns `'medium'` (0.4 < diff < 0.6) |
| Tier — Hard (semantic, ~3%) | Light: `bg-red-100` `#fee2e2` (text `text-red-800`) · Dark: `bg-red-900` (text `text-red-200`) · Gradient HEX dark: `#7f1d1d` | Fixture cell where `tier()` returns `'hard'` (diff ≥ 0.6) |
| Accent (10%) — Owned highlight | Light: `bg-blue-50/40` overlay + `border-l-2 border-l-blue-500` · Dark: `bg-blue-950/30` overlay + `border-l-2 border-l-blue-500` | **HEAT-08 ONLY** — left border + faint background tint on rows where `ownedTeamIds.has(team_id)`. Independent of filter state. Subtle alpha so green/amber/red tier colours remain dominant in the cell. |
| Accent (10%) — Active control | Light: `bg-zinc-900 text-white` · Dark: `bg-white text-zinc-900` | Selected pill state for HorizonToggle, AttDefToggle, OwnedFilterToggle (matches existing `GwToggle.tsx:111`/`AttDefToggle.tsx:22` precedent — high-contrast inversion, NOT the blue accent) |
| Destructive | not used | Phase 75 has no destructive actions (no deletes, no rollbacks, no submits) |

**Accent reserved for (explicit list — every appearance enumerated):**
1. Owned-team row left-border indicator (`border-l-blue-500`) — HEAT-08
2. Owned-team row background tint (`bg-blue-50/40` light / `bg-blue-950/30` dark) — HEAT-08
3. Selected state of horizon pill (8/12/16) — high-contrast inverse, NOT blue
4. Selected state of ATT/DEF toggle — high-contrast inverse, NOT blue
5. Selected ("active") state of "Owned only" toggle when pressed — high-contrast inverse, NOT blue

Tier semantic colours (green/amber/red) are NOT counted as the 10% accent — they encode data, not interaction state. They are the visual contract for the grid itself.

**Dark-mode gradient hex constants (D-05 — to be added in `FixtureHeatMap.tsx`):**

```typescript
const TIER_HEX: Record<DifficultyTier, string> = {
  easy:   '#dcfce7',  // green-100 (existing)
  medium: '#fef3c7',  // amber-100 (existing)
  hard:   '#fee2e2',  // red-100   (existing)
}
const TIER_HEX_DARK: Record<DifficultyTier, string> = {
  easy:   '#14532d',  // green-900
  medium: '#78350f',  // amber-900
  hard:   '#7f1d1d',  // red-900
}
```

**Text-on-gradient contrast (RESEARCH Pitfall 5):** opponent abbreviation `<span>`s on DGW gradient cells use `text-zinc-900 dark:text-zinc-100` so they remain legible regardless of the inline gradient theme. Single-fixture cells inherit text colour from their `TIER_CLASSES` entry (already contrast-checked in Phase 66).

## Interaction States

Every interactive element must support all four states. Disabled is not optional.

| Element | Default | Hover | Active/Pressed | Disabled |
|---------|---------|-------|----------------|----------|
| HorizonToggle button (unselected) | `bg-white dark:bg-zinc-800 text-zinc-700 dark:text-zinc-300 font-normal` | `hover:bg-zinc-50 dark:hover:bg-zinc-700` | `active:scale-95` (Tailwind) | n/a (always enabled) |
| HorizonToggle button (selected) | `bg-zinc-900 dark:bg-white text-white dark:text-zinc-900 font-bold` | (no hover state on selected — matches `GwToggle`) | `active:scale-95` | n/a |
| AttDefToggle | (verbatim — same rules as HorizonToggle) | | | n/a |
| OwnedFilterToggle (default, can-toggle) | `bg-white dark:bg-zinc-800 text-zinc-700 dark:text-zinc-300 font-normal` | `hover:bg-zinc-50 dark:hover:bg-zinc-700` | `aria-pressed="false"`; `active:scale-95` | n/a |
| OwnedFilterToggle (active, filter on) | `bg-zinc-900 dark:bg-white text-white dark:text-zinc-900 font-bold` | (no hover) | `aria-pressed="true"`; `active:scale-95` | n/a |
| OwnedFilterToggle (disabled — `submittedId === null`) | `opacity-50 cursor-not-allowed`; renders in default colour palette | no hover | no press | `disabled` attribute, `aria-disabled="true"`, native `title` tooltip |
| Fixture cell | colour by `TIER_CLASSES` (single) or inline gradient (DGW) | (no hover) — relies on native `title` tooltip | n/a | n/a |
| Owned-team row | left-border + tint always | n/a | n/a | n/a |

**Transitions:** `transition-all` on toggle buttons (matches `GwToggle.tsx:108`). Cell theme transitions are instant (no animation) — class-based dark mode is a binary state change.

**Reset behaviour (RESEARCH Open Question 2):** when `submittedId` changes (user resubmits a different team ID), `ownedOnly` resets to `false` via `useEffect(() => setOwnedOnly(false), [submittedId])`. Avoids confusing partial-filter state across team switches.

**Persistence (RESEARCH Open Question 3):** none for v1. `horizon`, `mode`, and `ownedOnly` are in-memory React state only; reset on page reload. Default values: `horizon = 8`, `mode = 'ATT'`, `ownedOnly = false`.

## Accessibility Contract

| Concern | Decision |
|---------|----------|
| Toggle group semantics | `role="group"` + `aria-label` on each toggle wrapper (matches `GwToggle`/`AttDefToggle`). Buttons inside use `aria-pressed={value === option}`. |
| Keyboard | All buttons receive native focus from `<button>` elements (no custom focus mgmt). Tab order: HorizonToggle (3 buttons) → AttDefToggle (2) → OwnedFilterToggle (1) → table contents are decorative `<td>`s with `title` only (already the Phase 66 baseline). |
| Tap target | All interactive controls `min-h-[44px]` (WCAG 2.5.5 Level AAA). |
| Tooltips | Native `title` attribute on cells and the disabled OwnedFilterToggle (project-wide convention; `VarianceBadge`/`DifferentialBadge` precedent). NOT a Radix/custom tooltip. |
| Colour as sole information | Tier colour PLUS opponent abbreviation text PLUS native tooltip = three independent channels. Colour-blind users still get the abbreviation and the difficulty number via tooltip. (HEAT-04 strengthens Phase 66's colour-only encoding — required to satisfy WCAG 1.4.1.) |
| Owned-row indicator | `border-l-blue-500` + `bg-blue-50/40` tint = colour PLUS shape (left border thickens the row's left edge by 2px, visible without colour vision). Also satisfies WCAG 1.4.1. |
| Live theme reactivity | `MutationObserver` on `<html>.classList` triggers re-render of inline-style gradient cells (RESEARCH Pattern 2). Without this, gradient cells go stale after `ThemeToggle` click — accessibility regression for dark-mode users. |
