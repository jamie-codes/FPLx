### Player Chip Pattern (within RivalDetailPanel sub-sections)

Each player displayed as an inline chip:

```
[web_name] [xPts label (optional)] [badge (optional)]
```

- Container: `rounded border border-zinc-100 dark:border-zinc-700 bg-zinc-50 dark:bg-zinc-800 px-3 py-2 flex flex-wrap items-center gap-x-2 gap-y-1`
- Player name: `text-sm font-medium text-zinc-900 dark:text-zinc-100`
- xPts value: `text-xs text-zinc-500 dark:text-zinc-400`
- Badge (threat/advantage/blocking): inline `<span>` using semantic badge colors above

Source: `CaptaincyPanel.tsx` candidate row pattern; `TransferPanel.tsx` suggested transfer row pattern.

### Rival Summary Table Columns

| Column | Mobile | Desktop | Notes |
|--------|--------|---------|-------|
| Rank | visible | visible | numeric, right-align |
| Manager Name | visible | visible | truncate overflow |
| Rank Gap | visible | visible | show `+N` / `-N` with color: green for positive gap (user ahead), red for negative (rival ahead), zinc for 0 |

## Interaction Contracts

### League ID Input

1. User types a numeric league ID into the input field.
2. localStorage key `fplx_mini_league_id` pre-fills the input on mount (CONTEXT.md D-02).
3. User clicks "Load Rivals" or presses Enter (form submit).
4. `submittedLeagueId` updates; value persists to localStorage immediately on submit.
5. `useRivals` hook fires with the submitted ID.

Validation guard: `enabled: !!leagueId && /^\d+$/.test(leagueId)` — button disabled and query suppressed if non-numeric input. Show inline validation message: `text-xs text-red-600 dark:text-red-400` below input.

### Rival Row Selection (D-06)

1. User clicks any row in `RivalSummaryTable`.
2. Clicked row gains `bg-zinc-100 dark:bg-zinc-800` highlight.
3. `RivalDetailPanel` below the table updates to show that rival's detail.
4. Only one rival detail visible at a time — switching rows replaces panel content without animation.
5. No row selected on initial load — detail panel shows "Select a rival to see differential analysis." placeholder text.

### Batch Fetch Progress

During the p-limit(3) batched rival fetch:
- Show `text-sm text-zinc-500 dark:text-zinc-400` progress note: `Loading rivals… (X / 20)`
- Progress derived from settled Promises in the `useRivals` queryFn.
- On completion, replace progress note with the summary table.

### Captain Edge Display (ML-07)

- Post-deadline AND user has a squad loaded: `Captain edge: +X.X xPts vs [Rival Name]` (green if positive) or `Captain edge: −X.X xPts vs [Rival Name]` (red if negative).
- Pre-deadline OR user has no squad loaded: `—` with `title` tooltip: `"Captain picks are only available after the GW deadline."`
- Sign convention: positive = user's captain candidate outperforms rival's pick (user advantage).
- Format: one decimal place, `+` prefix for positive values.

## States Required

For each major component:

### RivalsTab

| State | Trigger | UI Response |
|-------|---------|-------------|
| Initial (no leagueId) | First load, no localStorage value | Empty state with input form |
| Pre-filled (localStorage) | Return visit | Input pre-filled, submit required to load |
| Loading | After submit, fetch in progress | Progress note "Loading rivals… (X / 20)" |
| Error — fetch failed | Network error or non-200 response | Error message with `text-red-600` |
| Error — invalid input | Non-numeric characters in input | Inline validation message, submit blocked |
| Success | Fetch complete | Summary table rendered |
| League > 20 rivals | standings.results.length > 20 | Large league note above table |

### RivalSummaryTable

| State | Trigger | UI Response |
|-------|---------|-------------|
| No selection | Initial load | All rows in default state; detail panel shows placeholder |
| Row selected | Click | Selected row highlighted; detail panel updates |
| Pre-deadline captain | `rival.captainPlayerId === null` | Em-dash in Captain column |
| Post-deadline captain | `rival.captainPlayerId !== null` | Player `web_name` in Captain column |

### RivalDetailPanel

| State | Trigger | UI Response |
|-------|---------|-------------|
| No rival selected | No row selected | Placeholder text |
| Loading players | `usePlayers()` loading | "Loading…" text |
| Captain Edge — pre-deadline | `rival.captainPlayerId === null` | Em-dash |
| Captain Edge — post-deadline | `rival.captainPlayerId !== null` + user squad loaded | `±X.X xPts` with sign colour |
| Empty sub-section | No players in that category | Em-dash or section-specific empty copy |
