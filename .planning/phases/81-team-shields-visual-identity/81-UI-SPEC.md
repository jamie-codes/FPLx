## Component Inventory

### 1. `useTeamBadge` Hook (new — SHD-03)

**File:** `src/lib/hooks/useTeamBadge.ts`

**Signature:**
```ts
function useTeamBadge(shortName: string): {
  src: string | null
  onError: () => void
  showFallback: boolean
  fallbackColour: string
  initial: string
}
```

**Behaviour contract:**
- `src`: `teamBadgeUrl(TEAM_BADGE_CODE[shortName])` when `TEAM_BADGE_CODE[shortName]` exists, otherwise `null`.
- `onError`: sets internal `useState(false)` imgError flag to `true`. Stable per mount — no `useCallback` needed.
- `showFallback`: `src === null || imgError === true`.
- `fallbackColour`: `getTeamColour(shortName).primary`.
- `initial`: `shortName[0]` (first character of the 3-char abbreviation, e.g. "A" for "ARS").
- Single `useState<boolean>(false)` internally. No other state.
- Imports: `teamBadgeUrl` from `@/lib/fpl-images`, `TEAM_BADGE_CODE` and `getTeamColour` from `@/lib/team-colours`.

### 2. Ghost Watermark Crest — SetPieceTakerPanel (SHD-01)

**Host element:** the `<div>` per team card, currently:
```
className="rounded border border-zinc-200 dark:border-zinc-700 bg-white dark:bg-zinc-900 p-3"
```

**Required change:** add `relative overflow-hidden` to the card div class (verify not already present before adding).

**Ghost crest element — rendered when `!showFallback`:**
```
position: absolute
inset: auto 0 0 auto   (right: 0; bottom: 0)
width: 56px (w-14)
height: 56px (h-14)
opacity: 10% (opacity-10)
pointer-events: none (pointer-events-none)
object-fit: contain (object-contain)
aria-hidden: true
```

Tailwind classes: `absolute bottom-0 right-0 w-14 h-14 opacity-10 pointer-events-none object-contain`

**When `showFallback`:** do NOT render anything for the ghost position. The fallback swatch is NOT shown as a ghost watermark — an opaque coloured circle at opacity-10 looks wrong. Ghost position renders nothing on fallback.

**Image tag:**
```tsx
{/* eslint-disable-next-line @next/next/no-img-element */}
<img
  src={src}
  alt=""
  aria-hidden="true"
  className="absolute bottom-0 right-0 w-14 h-14 opacity-10 pointer-events-none object-contain"
  onError={onError}
/>
```

**Integration:** `useTeamBadge(team.team_short_name)` called inside the `data.teams.map((team) => ...)` block. Each card gets its own hook call.

### 3. Heat Map Row Header Crest — FixtureHeatMap (SHD-02)

**Host element:** the row `<th scope="row">`, currently:
```
className="px-2 py-1 text-left font-mono text-xs w-16 h-8"
```

**Required change:** `w-16` → `w-20`. Add flex layout to inner content.

**New `<th>` structure:**
```tsx
<th scope="row" className="px-2 py-1 text-left font-mono text-xs w-20 h-8">
  <span className="flex items-center gap-1">
    {showFallback ? (
      <span
        className="w-5 h-5 rounded-full flex items-center justify-center text-white font-bold text-xs shrink-0"
        style={{ background: fallbackColour }}
        aria-label={`${t.team_short_name} crest fallback`}
      >
        {initial}
      </span>
    ) : (
      // eslint-disable-next-line @next/next/no-img-element
      <img
        src={src}
        alt={`${t.team_short_name} crest`}
        width={20}
        height={20}
        className="w-5 h-5 object-contain shrink-0"
        onError={onError}
      />
    )}
    <span>{t.team_short_name}</span>
  </span>
</th>
```

**Crest size:** 20px × 20px (w-5 h-5). Fits within h-8 (32px) row height with px-2 py-1 padding.

**Sticky column safety:** the sticky behaviour is on the `<th>` itself — widening from w-16 to w-20 does not break stickiness. Verify that `min-w-[640px]` on the table is still sufficient after the 4px expansion.

### 4. Fallback Swatch Specifications

Two size variants, one per placement:

| Placement | Size | Classes |
|-----------|------|---------|
| Heat map row header | 20px × 20px | `w-5 h-5 rounded-full flex items-center justify-center text-white font-bold text-xs shrink-0` |
| Ghost watermark (SetPieceTakerPanel) | NOT shown as swatch (ghost renders nothing on fallback) | n/a |

**Ghost fallback rule:** No swatch at the ghost position. A coloured circle with an initial letter at opacity-10 would be unreadable and visually incorrect. Omit the element entirely when `showFallback` is true in the ghost context.

### 5. LineupTab Refactor (discretionary — SHD-03 extension)

**Scope:** Replace the inline `useState(false)` + `setKitError(true)` pattern in `LineupTab.tsx` (PlayerCard sub-component, lines 44–47) with `useTeamBadge`.

**Decision:** Proceed if it is a one-liner import swap. Do NOT restructure PlayerCard for this change — only replace the 3 lines of kit-error boilerplate.

**Constraint:** LineupTab uses `teamKitUrl` (kit shirt image), not `teamBadgeUrl` (crest). The `useTeamBadge` hook returns a badge URL. The refactor applies to the **fallback colour + initial logic only**, not the `src` field — LineupTab keeps its own `src={teamKitUrl(teamCode)}` with `onError={onError}` from the hook. The fallback swatch in LineupTab already uses a square div (not rounded-full) — that shape is preserved; only the state management migrates to the hook.

## Accessibility Contract

| Element | Requirement |
|---------|-------------|
| Ghost crest `<img>` | `alt=""` + `aria-hidden="true"` — decorative, screen readers skip |
| Heat-map crest `<img>` | `alt="{shortName} crest"` — informative; team already conveyed by adjacent abbrev text, so alt may be empty string if the abbrev span is always present |
| Fallback swatch (heat map) | `aria-label="{shortName} crest fallback"` — communicates the fallback state |
| Fallback swatch (LineupTab) | Existing `role="img"` + `aria-label="{team} team colour"` pattern — preserve as-is |
| `pointer-events-none` on ghost | Prevents ghost crest from intercepting clicks on card content |
