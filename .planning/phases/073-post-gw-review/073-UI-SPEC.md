## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding (gap-1) |
| sm | 8px | Compact element spacing (gap-2, p-2) |
| md | 16px | Default element spacing (gap-4, p-4, space-y-4) |
| lg | 24px | Section padding (space-y-6, mt-6) |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- GW pill toggle gap: gap-1 (4px) between pills — consistent with RESEARCH.md Pattern 3 GW pill code
- Stat grid gap: gap-3 (12px) between stat cards — matches LineupTab inner spacing
- Touch targets: min-h-[44px] on all interactive buttons (GW pills, Reset-equivalent) — consistent with GwToggle.tsx

Source: extracted from `GwToggle.tsx`, `LineupTab.tsx`, `DecisionSummaryTab.tsx`, `ProseSummaryBlock.tsx`.

- Player names (top scorer, captain name) rendered at text-sm font-semibold
- GW pill labels: text-xs font-semibold — matches LineupTab player name convention

Source: RESEARCH.md Pattern 3 + codebase patterns from LineupTab and ProseSummaryBlock.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff / #0a0a0a (dark) | Background, surfaces, page background |
| Secondary (30%) | zinc-50/800 (light/dark) | Stat cards, section container: `bg-zinc-50 dark:bg-zinc-800/40` |
| Accent (10%) | zinc-900 / zinc-100 (dark) | Active GW pill fill, section CTA |
| Positive delta | green-600 / green-400 (dark) | captain_delta = 0 ("Optimal captain"), positive xPts totals |
| Warning / missed | amber-800 / amber-200 (dark) | captain_delta > 0 (missed points) |
| Destructive | red-700 / red-300 (dark) | API error states, 503 error card border |

Accent reserved for:
- Active GW pill button background only (`bg-zinc-900 dark:bg-zinc-100 text-white dark:text-zinc-900`)
- No other interactive affordance uses accent fill

Color rules:
- `captain_delta = 0`: label reads "Optimal captain — no delta"; value displayed in `text-green-600 dark:text-green-400`
- `captain_delta > 0`: label reads "Captain delta"; value displayed in `text-amber-700 dark:text-amber-300` with prefix "+"
- `bench_pts_left`: always `text-zinc-900 dark:text-zinc-100` — neutral, factual stat
- `your_score` vs `average_score` comparison: if `your_score > average_score` value in `text-green-600 dark:text-green-400`; if below in `text-zinc-700 dark:text-zinc-300` — no red for score (not destructive)
- Inactive GW pills: `text-zinc-500 dark:text-zinc-400 hover:text-zinc-700 dark:hover:text-zinc-200`

Source: CONTEXT.md specifics + RESEARCH.md Pattern 3 code + LineupTab/GwToggle codebase patterns.

## Component Layout

### GwReviewTab — overall structure

```
<section mt-6 space-y-3 data-testid="gw-review-tab">
  <header flex items-center justify-between>
    <h2 text-base font-semibold>GW Review</h2>
    <!-- GW pill toggle: last 3 settled GWs -->
  </header>

  <!-- GW pill toggle -->
  <div role="group" aria-label="Gameweek" flex gap-1>
    {settledGws.map(gw => <button rounded-full px-3 py-1 text-xs font-semibold ...>GW{gw}</button>)}
  </div>

  <!-- Stat grid: 2×2 on mobile, 2×3 or 4-column row on desktop -->
  <div class="grid grid-cols-2 sm:grid-cols-4 gap-3">
    <StatCard label="GW Score"        value={your_score} />
    <StatCard label="Bench pts left"  value={bench_pts_left} />
    <StatCard label="Captain delta"   value={captain_delta} sentiment />
    <StatCard label="FPL average"     value={average_score} />
  </div>

  <!-- Top scorer detail row -->
  <div rounded border px-3 py-2>
    <span text-xs text-zinc-500>Top scorer</span>
    <span text-sm font-semibold>{top_scorer_name} — {top_scorer_pts}pts</span>
  </div>

  <!-- Captain detail row (when delta > 0) -->
  <div rounded border px-3 py-2>
    <span text-xs text-zinc-500>Captain</span>
    <span text-sm font-semibold>{captain_name}</span>
    <span text-xs text-zinc-500 ml-2>Optimal: {optimal_captain_name}</span>
  </div>
</section>
```

### StatCard sub-component

```
<div rounded border border-zinc-200 dark:border-zinc-700
     bg-white dark:bg-zinc-900 p-3>
  <p text-xs text-zinc-500 dark:text-zinc-400 mb-1>{label}</p>
  <p text-xl font-semibold {sentimentColor}>{value}</p>
</div>
```

- No external component library. StatCard is an inline sub-component of GwReviewTab (same pattern as PlayerCard in LineupTab).
- Sentiment color: see Color section above.

### GW Pill Toggle

- Element: `<button>` with `role="group"` on wrapper div, `aria-pressed={active}` on each button
- Shape: `rounded-full` (pill shape) — matches CONTEXT.md specifics
- Active state: `bg-zinc-900 dark:bg-zinc-100 text-white dark:text-zinc-900`
- Inactive state: `text-zinc-500 dark:text-zinc-400 hover:text-zinc-700 dark:hover:text-zinc-200`
- Wrapper: `flex gap-1` with no outer border (pill style, unlike GwToggle which uses a bordered group)
- Note: this differs from `GwToggle.tsx` (which uses grouped border); CONTEXT.md specifics call for rounded pill buttons, not the grouped border style

Source: RESEARCH.md Pattern 3 code + CONTEXT.md specifics.

## States & Guards

All states must have matching `data-testid` attributes for RTL tests.

| State | Trigger | Render |
|-------|---------|--------|
| No team ID | `teamId === ''` | Empty-state card (see Copywriting) |
| Loading | `isLoading` TanStack Query | Loading skeleton card (same border/padding as section card) |
| GW not settled / Blob missing | API returns 503 or `{ gw: null }` | Unsettled-state card (see Copywriting) |
| API error (503/502) | `isError` TanStack Query | Error card (red border, see Copywriting) |
| Data loaded | `data` present | Full stat grid + detail rows |

Loading state: render a `rounded border border-zinc-200 dark:border-zinc-700 p-4` container with text "Loading GW review..." in `text-sm text-zinc-500 dark:text-zinc-400`. No spinner component (no icon library).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Section heading | GW Review |
| Sub-tab label (page.tsx) | Review |
| Sub-tab mobileLabel | Review |
| Primary CTA | none — display-only tab, no primary action |
| Empty state heading | No squad loaded |
| Empty state body | Load your squad to see GW reviews. |
| Unsettled GW state | GW review will appear once scores finalise. |
| Loading state | Loading GW review... |
| Error state (503 cold start) | Review data unavailable — check back after the next pipeline run. |
| Error state (generic) | Unable to load GW review. Please try again. |
| Captain delta = 0 label | Optimal captain — no delta |
| Captain delta > 0 display | +{N}pts missed |
| Top scorer row label | Top scorer |
| Captain row label | Captain |
| Optimal captain suffix | Optimal: {name} |
| FPL average stat label | FPL average |
| GW Score stat label | GW Score |
| Bench pts left stat label | Bench pts left |
| Captain delta stat label | Captain delta |
| GW pill prefix | GW{N} (e.g. "GW33") |

Copywriting rules:
- NEVER use "top-10k average" — must be "FPL average" (CONTEXT.md D-08, RESEARCH.md D-08)
- Empty state guard text is identical to other Squad sub-tabs — do NOT invent a unique variant
- Bench pts stat is a fact, not a warning — do not add negative connotation
- Captain delta copy uses "missed" only when delta > 0; delta = 0 is "no delta" (positive framing)

Source: CONTEXT.md D-08, D-11, D-12, D-13 + RESEARCH.md matching decisions.

## Accessibility

- GW pill toggle wrapper: `role="group"` with `aria-label="Gameweek"`, each pill has `aria-pressed={boolean}`
- Stat cards: each `<div>` has no interactive role; values are plain text (screen-reader readable)
- Section: `<section>` with `data-testid="gw-review-tab"` for RTL and assistive tech landmark
- Captain delta sentiment: communicate meaning via text label, not color alone (color is supplementary)
- Min touch target: 44px height on all pill buttons (`min-h-[44px]`)
