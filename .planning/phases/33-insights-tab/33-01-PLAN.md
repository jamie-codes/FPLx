MIN_SAMPLE_TOTAL = 10

**3. Public entry point — `compute_insights()`**

```python
def compute_insights(
    merged: list,
    bootstrap: dict,
    fixtures: list,
    summaries: dict,
    finished_gws: int,
) -> list:
    """Aggregate season data into a flat list of Insight dicts for insights.json.

    Args:
        merged: list of merged player records (from merge_players())
        bootstrap: full FPL bootstrap-static JSON (elements, teams, events)
        fixtures: list of all fixture dicts (380 entries; finished + upcoming)
        summaries: dict mapping player_id (int) -> element-summary dict
        finished_gws: count of finished gameweeks

    Returns:
        Flat list of Insight dicts. Each dict has six keys: id, category, statement,
        confidence_pct, sample_n, sample_total. Output is sorted by
        (category ascending, confidence_pct descending). Insights with sample_total
        < MIN_SAMPLE_TOTAL or id in _TRIVIAL_PATTERN_IDS are filtered out.
    """
    raw = []
    raw.extend(_defensive_patterns(merged, bootstrap, fixtures))
    raw.extend(_attacking_patterns(merged, bootstrap, fixtures, summaries))
    raw.extend(_player_patterns(merged, summaries, finished_gws))
    raw.extend(_captaincy_patterns(merged, summaries))

    insights = []
    for ins in raw:
        if ins is None:
            continue
        if ins.get('sample_total', 0) < MIN_SAMPLE_TOTAL:
            continue
        if ins.get('id') in _TRIVIAL_PATTERN_IDS:
            continue
        # Defensive shape check: drop any dict missing required keys.
        required = {'id', 'category', 'statement', 'confidence_pct', 'sample_n', 'sample_total'}
        if not required.issubset(ins.keys()):
            continue
        if ins['category'] not in CATEGORIES:
            continue
        insights.append(ins)

    insights.sort(key=lambda i: (i['category'], -i['confidence_pct']))
    return insights
```

**4a. `_defensive_patterns(merged, bootstrap, fixtures) -> list`**

Required patterns (each emits one Insight if its sample floor is met):

- `id='def_cs_home_vs_away'` — clean-sheet rate at home vs away across all finished fixtures. Compute: home CS count = number of finished fixtures where `team_a_score == 0` (home team kept CS); away CS count = number of finished fixtures where `team_h_score == 0` (away team kept CS). `sample_total` = number of finished fixtures (both buckets pooled — use total finished fixtures count). `sample_n` = the larger of {home_cs, away_cs}. `confidence_pct` = larger / total * 100, rounded 1dp. `statement` = `f'Home teams keep {home_pct}% of clean sheets ({home_cs}/{total} finished fixtures), away teams keep {away_pct}%.'` Use the helper to compare; emit only if `total >= MIN_SAMPLE_TOTAL`.
- `id='def_cs_rate_top6_vs_rest'` — clean-sheet rate of the top 6 PL teams (by current `bootstrap['teams']` order; use teams sorted by `position` ascending — FPL bootstrap teams have a `position` field. If `position` is missing, fall back to top 6 by total points scored across `fixtures`). For each top-6 team, count CS (no goals conceded in finished home OR away fixtures). `sample_total` = total finished fixtures featuring a top-6 team. `sample_n` = CS count. `confidence_pct = sample_n / sample_total * 100`. Statement: `f'Top-6 teams kept clean sheets in {confidence_pct}% of their finished fixtures ({sample_n}/{sample_total}).'`
- `id='def_cs_streak_ge2'` — fraction of teams that have a current 2+ finished-fixture clean sheet streak. Iterate each team, walk their `summaries`-independent fixture history (use `fixtures` only, sorted by `event` ascending and filter `finished == True`); track for each team the longest CURRENT trailing CS streak (consecutive finished fixtures where they conceded 0). `sample_total` = 20 (PL teams). `sample_n` = number of teams with current streak >= 2. Emit only if `sample_total >= MIN_SAMPLE_TOTAL` (always true: 20 >= 10). Statement: `f'{sample_n} of 20 teams are on a clean-sheet streak of 2 or more fixtures ({confidence_pct}%).'`

Helper structure example (use as the template for each pattern function — copy this style):
```python
def _defensive_patterns(merged: list, bootstrap: dict, fixtures: list) -> list:
    """Emit defensive-pattern Insight dicts (CS rates by venue, top-6, streaks)."""
    out = []
    finished = [f for f in fixtures if f.get('finished')]
    total = len(finished)
    if total >= MIN_SAMPLE_TOTAL:
        home_cs = sum(1 for f in finished if (f.get('team_a_score') or 0) == 0)
        away_cs = sum(1 for f in finished if (f.get('team_h_score') or 0) == 0)
        # Pick the dominant side for the headline percentage.
        if home_cs >= away_cs:
            sample_n = home_cs
            home_pct = round(home_cs / total * 100, 1)
            away_pct = round(away_cs / total * 100, 1)
        else:
            sample_n = away_cs
            home_pct = round(home_cs / total * 100, 1)
            away_pct = round(away_cs / total * 100, 1)
        out.append({
            'id': 'def_cs_home_vs_away',
            'category': 'defensive',
            'statement': f'Home teams keep clean sheets in {home_pct}% of finished fixtures ({home_cs}/{total}), away teams in {away_pct}%.',
            'confidence_pct': round(max(home_cs, away_cs) / total * 100, 1),
            'sample_n': sample_n,
            'sample_total': total,
        })
    # ... (repeat the same shape for def_cs_rate_top6_vs_rest and def_cs_streak_ge2)
    return out
```

**4b. `_attacking_patterns(merged, bootstrap, fixtures, summaries) -> list`**

Required patterns:

- `id='att_top_xg_overperformers'` — attackers (`element_type` in {3, 4}) whose `goals_scored` exceeds `expected_goals` by 30% or more (and `expected_goals >= 3.0` to avoid noise). `sample_total` = count of `element_type in {3,4}` players with `expected_goals >= 3.0`. `sample_n` = count overperforming by 30%+. Statement: `f'{sample_n} of {sample_total} attackers (xG >= 3) have outscored their xG by 30%+ this season ({confidence_pct}%).'`
- `id='att_home_goal_share'` — fraction of finished-fixture goals scored by the home team. Compute total home goals = `sum((f.get('team_h_score') or 0) for f in finished)`, total away goals likewise, total goals = home + away. `sample_total = total goals`. `sample_n = home goals`. `confidence_pct = home / total * 100`. Statement: `f'{confidence_pct}% of all goals this season have been scored by the home team ({sample_n}/{sample_total}).'`
- `id='att_top_team_goal_share'` — share of goals scored by the top-scoring team relative to the league total. Per team, sum goals across finished fixtures (sum `team_h_score` for home games + `team_a_score` for away games). `sample_total = total goals all teams`. `sample_n = top team goals`. Statement: `f'{top_team_short_name} have scored {confidence_pct}% of all PL goals this season ({sample_n}/{sample_total}).'`

**4c. `_player_patterns(merged, summaries, finished_gws) -> list`**

Required patterns:

- `id='player_buy_signal_count'` — fraction of players (with `total_points >= 50` to avoid spam) flagged as `regression_signal == 'buy'`. `sample_total` = count of qualifying players (total_points >= 50). `sample_n` = count with `regression_signal == 'buy'`. Statement: `f'{sample_n} of {sample_total} regular starters ({confidence_pct}%) carry a BUY signal — actual returns trail xG+xA over the last 5 GW.'`
- `id='player_sell_signal_count'` — same as above but `regression_signal == 'sell'`.
- `id='player_diff_count'` — fraction of qualifying players (total_points >= 50) flagged as `differential_flag == 'diff'`. Statement: `f'{sample_n} of {sample_total} regular starters ({confidence_pct}%) are differentials — high xPts with low ownership.'`
- `id='player_template_trap_count'` — same with `differential_flag == 'trap'`.

**4d. `_captaincy_patterns(merged, summaries) -> list`**

Required patterns:

- `id='cap_top3_xpts_share'` — share of total `xPts_1gw` accounted for by the top 3 players (descending by `xPts_1gw`). `sample_total = round(sum_all_xpts)` (cast to int). `sample_n = round(sum_top3_xpts)`. Confidence = top3 / total * 100. Use only players with `status == 'a'` and `xPts_1gw` set. Statement: `f'The top 3 captaincy options account for {confidence_pct}% of available xPts this GW ({sample_n}/{sample_total}).'`
- `id='cap_double_digit_haul_rate'` — across all summaries[*]['history'] entries this season, fraction of (player, match) appearances where `total_points >= 10`. `sample_total` = total appearances with `minutes > 0` across all players in summaries. `sample_n` = appearances with `total_points >= 10`. Statement: `f'Double-digit hauls (10+ pts) occur in {confidence_pct}% of player appearances ({sample_n}/{sample_total}).'`
