Create `pipeline/fpl_client.py` with three functions. The FPL API blocks the default python-requests User-Agent with 403, so a browser-like UA is required.

The file must define:
- Module-level constant `FPL_BASE = 'https://fantasy.premierleague.com/api'`
- Module-level dict `HEADERS` with User-Agent set to `'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36'`, Accept set to `'application/json, text/plain, */*'`, Accept-Language `'en-GB,en;q=0.9'`, Origin `'https://fantasy.premierleague.com'`, Referer `'https://fantasy.premierleague.com/'`
- `def get_bootstrap_static() -> dict` — GET `{FPL_BASE}/bootstrap-static/` with HEADERS, timeout=30, raise_for_status, return .json()
- `def get_fixtures() -> list` — GET `{FPL_BASE}/fixtures/` with same pattern
- `def get_element_summary(player_id: int) -> dict` — GET `{FPL_BASE}/element-summary/{player_id}/` with same pattern

Create `pipeline/upload.py` with three functions:
- `def upload_json(pathname: str, data: dict)` — imports vercel_blob, json.dumps the data to bytes, calls `vercel_blob.put(pathname, payload, {'allowOverwrite': True, 'contentType': 'application/json'})`, prints byte count
- `def save_local(pathname: str, data, cache_dir: str = 'pipeline/cache')` — os.makedirs(cache_dir, exist_ok=True), writes json.dumps(data, indent=2, ensure_ascii=False) to `{cache_dir}/{pathname}`, prints byte count
- `def save(pathname: str, data)` — checks `os.getenv('USE_BLOB', '').lower() == 'true'`, routes to upload_json or save_local

Create `pipeline/run.py` — pipeline entry point:
- Adds pipeline dir to sys.path so relative imports work from project root
- Loads dotenv
- Imports get_bootstrap_static, get_fixtures from fpl_client and save from upload
- `def run(dry_run: bool = False)` — if dry_run, prints config and returns. Otherwise, wrap the entire fetch+save pipeline in a try/except block:

  **Happy path (inside try):** (1) fetches bootstrap-static via get_bootstrap_static(), saves as 'fpl_bootstrap.json', (2) fetches fixtures via get_fixtures(), saves as 'fpl_fixtures.json', (3) writes 'last_updated.json' containing `{"last_updated": <ISO 8601 UTC timestamp>, "stale": false, "source": "blob"|"local", "player_count": N, "team_count": N, "fixture_count": N}`

  **Stale-cache fallback (inside except, per D-06):** On ANY exception during fetch/save:
  1. Print the error to stderr.
  2. Determine the cache dir (same logic as save — `pipeline/cache` for local mode).
  3. Check if `last_updated.json` already exists in the cache dir.
  4. If it exists: read the existing `last_updated.json`, overwrite its `stale` field to `true`, add an `error_message` field with `str(exception)`, and write it back.
  5. If it does NOT exist (first-ever run failed): write a new `last_updated.json` with `{"last_updated": <ISO 8601 UTC timestamp>, "stale": true, "source": "blob"|"local", "error_message": str(exception)}` (no player/team/fixture counts since data was not fetched).
  6. Exit with `sys.exit(1)` so GitHub Actions marks the run as failed.

  **Test hook for stale-cache path:** If the environment variable `MOCK_FAIL_VALIDATION` is set to `"true"`, raise a `RuntimeError("Mock validation failure for testing")` AFTER the dry-run check but BEFORE fetching data. This allows testing the stale-cache path without a real network failure.

- `if __name__ == '__main__'` block checks for `--dry-run` in sys.argv

Note: element-summary fetching is NOT in the daily run yet. It requires iterating ~700 players and will be added in Phase 4 (DefCon). The function exists in fpl_client.py for that future use.
