<objective>
Fix FIX-03 and FIX-04 — the GW Review top scorer card and best bench card both display 0 points for settled gameweeks because `pick.total_points` from the FPL picks endpoint is not backfilled with post-GW actual points. After this fix, both fields are populated from `event/{gw}/live/`, the canonical post-GW per-player points source.

Purpose: A "top scorer" card that always shows 0pts is worse than no card — it actively misinforms the user and undermines confidence in the entire GW Review surface. FIX-03 and FIX-04 share a single root cause (D-01) and a single fix (D-02), so they ship as one TDD pass with one new fetch and one shared `liveMap`.

Output: A new Step 4b in `gw-review/route.ts` that fetches `event/{gw}/live/` inside a standalone try/catch (mirroring the existing dream-team block at lines 150-169), a `liveMap: Map<number, number>` keyed by element id, Step 5 reductions and output fields rewritten to look up actual points from `liveMap` with `?? 0` fallback, and three new TDD test cases (top scorer, best bench, SC-5 graceful failure).
</objective>
