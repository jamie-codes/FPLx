Create `src/lib/gem-score.ts` implementing the scoring algorithm. Follow the RESEARCH.md "Gem Scoring Algorithm Detail" section precisely:

1. **DimensionStats interface** (internal, not exported):
```typescript
interface DimensionStats {
  fdr: { min: number; max: number }
  form: { min: number; max: number }
  xg: { min: number; max: number }
  xa: { min: number; max: number }
  ownership: { min: number; max: number }
  minutes: { min: number; max: number }
  setpiece: { min: number; max: number }
}
```

2. **Helper functions** (not exported):
- `minMax(values: number[]): { min: number; max: number }` -- returns `{ min: 0, max: 1 }` for empty arrays
- `normalise(value: number, stats: { min: number; max: number }): number` -- returns 0.5 when `max === min`, otherwise clamps to [0, 1]
- `setpieceRank(p: MergedPlayer): number` -- returns 2 if any of `penalties_order`, `direct_freekicks_order`, or `corners_and_indirect_freekicks_order` is 1; returns 1 if any is 2; returns 0 otherwise

3. **`computeAllGemScores(players: MergedPlayer[]): ScoredPlayer[]`** (exported):
- Pass 1: Compute raw FDR values per player (`1.0 - avgDifficulty`, use 0.5 when fixtures empty)
- Pass 1: Compute DimensionStats min/max across ALL players for: fdr, form (form_pts_per90), xg (non-null xg_per90 only), xa (non-null xa_per90 only), ownership (1 - parseFloat(selected_by_percent)/100), minutes (minutes_per90), setpiece (setpieceRank)
- Pass 2: For each player, normalise each dimension, collect non-null dims into array, gem_score = mean of that array
- Return `ScoredPlayer[]`

Key behaviors:
- xg_score is null (excluded from composite) when player.xg_per90 is null
- xa_score is null (excluded from composite) when player.xa_per90 is null
- gem_score denominator counts only non-null dimensions
