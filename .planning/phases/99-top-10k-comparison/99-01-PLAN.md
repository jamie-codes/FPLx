fields. The route fetches FPL's public `dream-team/{gw}/` endpoint in a standalone
try/catch, computes a benchmark score (sum of dream-team `team[*].points`), and surfaces up
to 3 dream-team players the user did not own (sorted desc by pts). On any dream-team

`benchmark_label = 'FPL average'` and `missed_players = []`.

extension is non-optional so the consuming React component (Plan 02) can rely on the
