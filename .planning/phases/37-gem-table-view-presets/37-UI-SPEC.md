## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Gap between controls in sticky bar (`gap-2`) |
| md | 16px | Horizontal page padding (`px-4`) |
| lg | 24px | Section margin-bottom (`mb-6`) |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Touch targets: minimum 44px height on mobile (`min-h-[44px]`, `py-2.5` on mobile / `py-1` on desktop). This applies to all buttons in the sticky controls bar including the new preset toggle — source: `GwToggle.tsx` line 54, `PositionFilter.tsx` line 24.
- Sticky controls bar: `py-2` vertical padding, `-mx-4 px-4` negative-margin bleed for full-width background — source: `GemTable.tsx` line 121.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff / #0a0a0a | Page background (`--background`): white in light, near-black in dark |
| Secondary (30%) | zinc-100 (light) / zinc-800 (dark) | Table alternate rows (`even:bg-gray-50 dark:even:bg-zinc-800`), sticky header/bar background (`bg-white dark:bg-zinc-900`) |
| Accent (10%) | zinc-900 (light) / white (dark) | Active/filled toggle button state only |
| Destructive | — | No destructive actions in this phase |

Accent reserved for: **active segmented button fill** on the preset toggle (`bg-zinc-900 dark:bg-white`) and the GwToggle. No other elements use this filled-black/white treatment.

Inactive button state: `bg-white dark:bg-zinc-800 text-zinc-700 dark:text-zinc-300` with hover `hover:bg-zinc-50 dark:hover:bg-zinc-700`.

Source: `GwToggle.tsx` lines 56–57 (active), lines 57–58 (inactive). The preset toggle must copy these classes verbatim per D-06.

Sticky bar background: `bg-white dark:bg-zinc-900` — identical to the table header background so the bar is flush and borderless on desktop. Source: `GemTable.tsx` line 121.

## Component Inventory

### PresetToggle (new)

Visual pattern: segmented button group — identical to `GwToggle`.

```
<div role="group" aria-label="Table view preset" className="hidden sm:flex rounded overflow-hidden border border-zinc-300 dark:border-zinc-600">
  {(['default', 'compact', 'analysis'] as const).map((p) => (
    <button
      key={p}
      onClick={() => onPresetChange(p)}
      aria-pressed={preset === p}
      className={`px-3 py-2.5 sm:py-1 text-sm font-medium transition-all cursor-pointer active:scale-95 min-h-[44px] ${
        preset === p
          ? 'bg-zinc-900 dark:bg-white text-white dark:text-zinc-900'
          : 'bg-white dark:bg-zinc-800 text-zinc-700 dark:text-zinc-300 hover:bg-zinc-50 dark:hover:bg-zinc-700'
      }`}
    >
      {label}
    </button>
  ))}
</div>
```

Wrapper uses `hidden sm:flex` (D-07): invisible on mobile, flex row on desktop.

Labels (sentence-case, concise):
- `default` → "Default"
- `compact` → "Compact"
- `analysis` → "Analysis"

## Interaction Contract

### Preset toggle

| Interaction | Behaviour |
|-------------|-----------|
| Click inactive preset button | Active preset changes; column visibility updates immediately |
| Click active preset button | No-op (already selected) |
| Tab switch (away and back) | Preset is unchanged — state lives in `page.tsx`, not GemTable local state (D-08) |
| Page load / session start | Initial preset is `'default'` (D-09) |
| Mobile viewport (< 640px) | Toggle is not rendered (`hidden sm:flex`) |

### Accessibility

- `role="group"` on the wrapper div with `aria-label="Table view preset"` — mirrors GwToggle pattern.
- `aria-pressed={preset === p}` on each button — mirrors GwToggle pattern (source: `GwToggle.tsx` line 53).
- Keyboard: native `<button>` elements are keyboard-focusable; no additional ARIA needed.

### State ownership

- `gemPreset` state declared in `page.tsx` alongside `activeSection` / `sectionMemory` (D-08).
- Passed to `GemTable` as props: `preset: ViewPreset` and `onPresetChange: (p: ViewPreset) => void`.
- No `sessionStorage` / `localStorage` — in-memory session persistence only (D-09).
