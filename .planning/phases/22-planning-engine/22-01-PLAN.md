    **Algorithm (per D-01 greedy + 1-level look-ahead):**

    ```
    simulatedSquad = [...picks] (as player ID set)
    simulatedBank = bankBalance
    currentFT = ftState

    for step = 0..horizon-1:
      targetGw = startingGw + step
      nextGw = (step < horizon - 1) ? startingGw + step + 1 : null

      // Check if fixture data exists for this GW
      unconfirmedFixtures = !allPlayers.some(p => p.fixtures.some(f => f.event_id === targetGw))

      // Build squad player lookup from simulatedSquad IDs
      squadPlayers = simulatedSquad positions 1-11 mapped to ScoredPlayer via allPlayers

      // Pre-filter candidates: top CANDIDATES_PER_POSITION per position by gem_score, not in squad
      candidatePool = for each position(1-4): allPlayers filtered(same position, not in squad), sorted by gem_score desc, take top 20

      // Score all (sell, buy) pairs
      for each sellPlayer in squadPlayers (starting XI only — position 1-11):
        sellPrice = sellPrices?.[sellPlayer.id] ?? sellPlayer.now_cost
        for each buyCandidate in candidatePool[sellPlayer.element_type]:
          if buyCandidate.now_cost > simulatedBank + sellPrice: skip (unaffordable)

          gwScore = (buyCandidate.proj_pts_1gw * fixtureCountForGw(buyCandidate, targetGw))
                  - (sellPlayer.proj_pts_1gw * fixtureCountForGw(sellPlayer, targetGw))
          lookAheadScore = 0
          if nextGw !== null:
            lookAheadScore = LOOK_AHEAD_DISCOUNT * (
              (buyCandidate.proj_pts_1gw * fixtureCountForGw(buyCandidate, nextGw))
              - (sellPlayer.proj_pts_1gw * fixtureCountForGw(sellPlayer, nextGw))
            )
          totalScore = gwScore + lookAheadScore
          hitCost = computeHitCost(currentFT.available, 1, null)  // 1 transfer per step
          netGain = totalScore + hitCost

          record as ScoredTransfer { sellId, buyId, gwScore, lookAheadScore, totalScore, hitCost, netGain, affordable: true }

      // Pick best: highest netGain, but only if netGain > 0 (per D-03)
      bestTransfer = scoredCandidates sorted by netGain desc, first where netGain > 0

      if bestTransfer found:
        // Apply transfer to simulated state
        update simulatedSquad: remove sellId, add buyId
        update simulatedBank: += sellPrice - buyPlayer.now_cost
        transfersIn = [bestTransfer.buyId]
        transfersOut = [bestTransfer.sellId]
        transfersUsed = 1
      else:
        // No beneficial transfer — save the FT
        transfersIn = []
        transfersOut = []
        transfersUsed = 0

      // Build PlanStep
      hitCost = computeHitCost(currentFT.available, transfersUsed, null)
      step = { gw: targetGw, chip: null, transfersIn, transfersOut,
               freeTransfersAvailable: currentFT.available, hitCost,
               scoredTransfers: top 5 candidates by netGain,
               squadAfter: [...simulatedSquad player IDs],
               unconfirmedFixtures }

      // Advance FT state for next step
      currentFT = computeNextFTState(currentFT.available, transfersUsed, null)
    ```

    - Per D-02: scoring is `proj_pts_1gw * fixtureCountForGw(player, gw)` — never use proj_pts_3gw or proj_pts_5gw

    - Per D-04: `sellPrices` parameter is optional — use `player.now_cost` as fallback

    - Use `snapshotSquad` from free-transfer-engine.ts for deep copy before look-ahead candidate evaluation
    - Starting XI only (position 1-11) as sell candidates — do not include bench (position 12-15)
