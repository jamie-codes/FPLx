## Chart Specification: DataHealthSparkline

### Layout

- Rendered as a sibling component inside `DataHealthPanel`, placed **between** the toggle button row and the collapsible `isExpanded` table.
- Renders only when `history` is defined: `{data?.history && <DataHealthSparkline history={data.history} />}`.
- When `history` is absent (legacy `data_health.json` without the field), component renders `null` silently — `DataHealthPanel` is visually unchanged.

### Dimensions

- `ResponsiveContainer width="100%" height={40}` — compact inline indicator.
- No border container div. The sparkline sits flush inside the panel's existing padding.
- Top margin: `mt-2` (8px) below the toggle button row.

### Axes

Both axes hidden — this is a sparkline, not an analytical chart.

```
<XAxis hide />
<YAxis hide domain={[0, 2]} />
```

- YAxis domain `[0, 2]` maps status to numeric: `ok=2`, `warning=1`, `error=0` — higher = healthier, so ok floats to top.
- This numeric mapping is a rendering-only concern internal to `DataHealthSparkline`. It is NOT stored in the JSON.

### Data Mapping

Transform `HistoryEntry[]` to chart data inside `DataHealthSparkline`:

```ts
const STATUS_Y = { ok: 2, warning: 1, error: 0 } as const
const chartData = history.map((e, i) => ({
  i,
  y: STATUS_Y[e.overall_status] ?? 0,
  timestamp: e.timestamp,
  overall_status: e.overall_status,
}))
```

### Cold-Start Placeholder

When `history` has exactly 1 entry OR `history` is an empty array (`[]`), render a single placeholder:

```ts
const isColdStart = history.length <= 1
```

- If `history.length === 0`: chartData is a single synthetic point `[{ i: 0, y: 2, timestamp: null, overall_status: 'ok' }]` — placeholder only.
- The tooltip for any point where `timestamp === null` displays `"First run"` in place of a timestamp.

### Connector Line

```jsx
<Line
  type="monotone"
  dataKey="y"
  stroke="rgba(161,161,170,0.4)"
  strokeWidth={1}
  dot={<SparklineDot />}
  activeDot={false}
  isAnimationActive={false}
  connectNulls={false}
/>
```

### Custom Dot Component

```tsx
function SparklineDot(props: any) {
  const { cx, cy, payload } = props
  const STATUS_COLOR = {
    ok:      'var(--color-positive)',
    warning: 'var(--color-warning)',
    error:   'var(--color-negative)',
  } as const
  const fill = payload.timestamp === null
    ? 'var(--muted)'
    : STATUS_COLOR[payload.overall_status as keyof typeof STATUS_COLOR] ?? 'var(--muted)'
  return <circle cx={cx} cy={cy} r={4} fill={fill} stroke="none" />
}
```

- Resting radius: 4px.
- No active dot enlargement on the sparkline (too compact; interaction is tooltip only).
- `activeDot={false}` on the Line to suppress recharts default blue active dot.

### Tooltip

```tsx
function SparklineTooltip({ active, payload }: any) {
  if (!active || !payload?.length) return null
  const entry = payload[0].payload
  if (entry.timestamp === null) {
    return (
      <div className="bg-white dark:bg-zinc-900 border border-zinc-200 dark:border-zinc-700 rounded px-2 py-1 text-xs">
        <p className="italic text-zinc-500 dark:text-zinc-400">First run</p>
      </div>
    )
  }
  const label = { ok: 'OK', warning: 'Warning', error: 'Error' }[entry.overall_status] ?? entry.overall_status
  return (
    <div className="bg-white dark:bg-zinc-900 border border-zinc-200 dark:border-zinc-700 rounded px-2 py-1 text-xs space-y-0.5">
      <p className="font-semibold text-zinc-900 dark:text-zinc-100">{label}</p>
      <p className="text-zinc-500 dark:text-zinc-400">{new Date(entry.timestamp).toLocaleString()}</p>
    </div>
  )
}
```

## Pitfall Register (carry-forward + new)

| ID | Pitfall | Rule |
|----|---------|------|
| Pitfall 4 | recharts numeric axis | `XAxis` hidden in sparkline — no `type="number"` issue; but any visible axis in this phase MUST use `type="number"` |
| Pitfall 6 | Optional fields | `history` is OPTIONAL on `DataHealth` — guard every access with `data?.history` |
| Pitfall 7 | `@types/recharts` | MUST NOT be installed — v1 type package is incompatible with recharts v3.x |
| Pitfall 8 (new) | `activeDot` default | recharts renders a blue active dot by default on `Line`; set `activeDot={false}` on the sparkline Line to suppress it — the `SparklineDot` custom dot handles hover state |
| Pitfall 9 (new) | Y-axis domain | `YAxis domain={[0, 2]}` is REQUIRED even when hidden — without it recharts auto-scales to the single-point data range and the dot placement is unpredictable for 1-entry history |
