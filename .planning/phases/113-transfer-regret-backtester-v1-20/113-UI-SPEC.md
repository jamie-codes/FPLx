## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inline padding (`px-1`, `py-0.5`) |
| sm | 8px | Compact element spacing, table cell padding (`py-1`), chart inner padding |
| md | 16px | Default element spacing, card padding, section inner padding |
| lg | 24px | Section padding, major element spacing |
| xl | 32px | Layout gaps between top-level sections |
| 2xl | 48px | Major section breaks |

- Touch targets: minimum 44px height on all interactive elements (`min-h-[44px]`) — applies to the Captain | Transfer pill toggle buttons, consistent with GwToggle pattern.

- Pill toggle margin: `mb-4` below the toggle before the summary header — separates the nav control from the content region.

Source: Inherited from Phase 96 UI-SPEC. No new exceptions for Phase 113 beyond those listed above.

## Color

All tokens are CSS custom properties defined in `src/app/globals.css` with `.dark:` Tailwind variants on every element.

| Role | Light Value | Dark Value | Usage |
|------|-------------|------------|-------|
| Dominant (60%) | `--background: #F7F8FC` | `#0a0a0a` | Page background, section wrappers |
| Secondary (30%) | `--surface: #ffffff` / `--surface-elevated: #f3f4f6` | `#111827` / `#1f2937` | Chart container, tooltip background, table row hover |
| Accent positive (10%) | `--color-positive: #22c55e` | `#22c55e` | Bars BELOW zero axis (user was better / good hold), positive delta cells, "You better" count |
| Accent negative (reserved) | `--color-negative: #ef4444` | `#ef4444` | Bars ABOVE zero axis (engine was better, user left pts on table), "Engine better" count, error state text |
| Muted / secondary text | `--muted: #6b7280` | `#9ca3af` | Empty-state copy, placeholder text, axis tick labels, "No snapshot" placeholder |
| Border | `--border: #e5e7eb` | `#374151` | Chart container border, table cell dividers, pill toggle border |

Accent reserved for:
- `color-positive` (#22c55e): transfer regret bars where `delta < 0` (user was better / good hold), "You better" count in season summary, positive delta text in transfer rows — copy `−{N}pts (good hold)`.
- `color-negative` (#ef4444): transfer regret bars where `delta > 0` (engine was better), "Engine better" count in season summary, error state messages — copy `+{N}pts (engine better)`.

No destructive actions in Phase 113 — no destructive confirmation color needed.

Bar fill constants (reuse existing from `BackTab.tsx`):
- `REGRET_RED = '#ef4444'` — delta > 0 (engine better)
- `REGRET_GREEN = '#22c55e'` — delta < 0 (user better / good hold)
- `REGRET_GREY = 'rgba(161,161,170,0.5)'` — delta === null (no snapshot) or delta === 0 (tied)

Dark mode bar adjustment for delta > 0: `#f87171` (red-400 equivalent) — matches Phase 96 pattern for dark mode contrast.

Source: Inherited from Phase 96 UI-SPEC. Color semantics extended for transfer delta direction per CONTEXT.md D-14.

## Component Inventory

### 1. Captain | Transfer Pill Toggle

**Pattern:** Reuse `GwToggle.tsx` segmented pill pattern exactly. Two options only.

```ts
type BackView = 'captain' | 'transfer'
```

**Implementation:** New `BackViewToggle` component (or inline in `BackTab.tsx` if small enough), following `GwToggle` structure:
- Wrapper: `role="group"` `aria-label="Backtester view"` `flex rounded overflow-hidden border border-zinc-300 dark:border-zinc-600`
- Each button: `px-3 py-2.5 sm:py-1 text-sm font-medium transition-all cursor-pointer active:scale-95 min-h-[44px]`
- Active: `bg-zinc-900 dark:bg-white text-white dark:text-zinc-900`
- Inactive: `bg-white dark:bg-zinc-800 text-zinc-700 dark:text-zinc-300 hover:bg-zinc-50 dark:hover:bg-zinc-700`

Labels: "Captain" | "Transfer"

State: `useState<BackView>('captain')` inside `BackTab`. Resets to `'captain'` on re-mount (CONTEXT.md D-09).

Placement: First visual element in `BackTab`'s render tree — before `SeasonSummaryHeader`. Wrapper: `mb-4`.

### 2. TransferRegretView Component

**Structure:** Parallel to the existing captain regret layout. Self-contained — own summary header + bar chart + per-GW rows (CONTEXT.md D-10). No shared chrome with captain view.

Render order when Transfer tab is active:
1. `TransferSeasonSummaryHeader` — season aggregate stats
2. `TransferRegretChart` — recharts bar chart
3. Per-GW detail rows table

### 3. Transfer Season Summary Header

**Structure:** Single `<div>` with flex layout, `mb-4 space-y-1`, renders above the chart.

Two lines of content:
- Line 1 (display): `Total transfer regret: {N}pts across {N} GWs` — `text-xl font-semibold` with color indicating net direction (positive total = `text-red-600 dark:text-red-400`, negative total = `text-green-600 dark:text-green-400`, zero = `text-zinc-600 dark:text-zinc-400`)
- Line 2 (body): `Engine better: {N} | You better: {N} | Tied: {N}` — `text-sm text-zinc-600 dark:text-zinc-400` with inline colored spans: engine-better in `text-red-600 dark:text-red-400`, you-better in `text-green-600 dark:text-green-400`, tied in `text-zinc-500 dark:text-zinc-400`

Source: CONTEXT.md D-13 defines the exact copy pattern.

### 4. Transfer Regret Bar Chart

**Library:** Recharts `BarChart` — reuse existing imports from `BackTab.tsx` (BarChart, Bar, Cell, XAxis, YAxis, ReferenceLine, Tooltip, ResponsiveContainer). No new imports required (CONTEXT.md code_context).

**Container:** `ResponsiveContainer width="100%" height={288}` inside chart wrapper div: `rounded border border-zinc-200 dark:border-zinc-700 bg-zinc-50 dark:bg-zinc-800 px-2 py-3 relative mb-4`

**Axes:**
- XAxis: `dataKey="gw"` type `"number"`, `tickFormatter={(v) => \`GW${v}\`}`, `tick={{ fontSize: 12, fill: 'currentColor' }}`, `axisLine={false}`, `tickLine={false}`
- YAxis: numeric (transfer delta pts), `tickFormatter={(v) => v >= 0 ? \`+${v}\` : \`${v}\`}`, `tick={{ fontSize: 12, fill: 'currentColor' }}`, `axisLine={false}`, `tickLine={false}`, `width={40}`

**Zero baseline:** `ReferenceLine y={0}` `stroke="rgba(161,161,170,0.5)"` `strokeWidth={1}` — bars above = engine was better; bars below = user was better / good hold.

**Bar fill:** Conditional per entry using `Cell` — reuse `REGRET_RED` / `REGRET_GREEN` / `REGRET_GREY` constants verbatim from `BackTab.tsx` (CONTEXT.md D-14):
- `delta > 0` (engine better): `fill="#ef4444"` light / `fill="#f87171"` dark
- `delta < 0` (user better / good hold): `fill="#22c55e"`
- `delta === 0` (tied) or `delta === null` (no snapshot): `fill="rgba(161,161,170,0.5)"`

**Tooltip:** New `TransferRegretTooltip` component — same structure as `RegretTooltip`. Shows: GW number, engine recommendation (`Sell {X} buy {Y}`), user action (`Sell {A} buy {B}` or `Held`), delta with signed label. Wrapper: `rounded border border-zinc-200 dark:border-zinc-700 bg-white dark:bg-zinc-900 px-3 py-2 text-xs shadow-sm`.

**Animation:** `isAnimationActive={false}` — matches existing chart convention.

**Aria:** `aria-label="Transfer regret per gameweek"` on the chart wrapper div.

### 5. Per-GW Transfer Detail Rows

**Structure:** `<table>` using existing locked classes — `TABLE_CLS`, `TH_CLS`, `TR_CLS`, `TD_CLS` from `BackTab.tsx`. Do NOT redefine.

**Columns (CONTEXT.md D-12):**
| Column | Content | Width hint |
|--------|---------|------------|
| GW | "GW{N}" | narrow, `w-12` |
| Engine | "Sell {PlayerOut} ({Xpts}) buy {PlayerIn} ({Ypts})" or "No model snapshot" | wide |
| You | "Sell {PlayerOut} ({Xpts}) buy {PlayerIn} ({Ypts})" or "Held — no transfer" | wide |
| Delta | Signed value with label | narrow, `text-right` |

**Delta cell rendering:**
- `delta > 0`: `text-red-600 dark:text-red-400` — copy: `+{N}pts (engine better)`
- `delta < 0`: `text-green-600 dark:text-green-400` — copy: `−{N}pts (good hold)`
- `delta === 0`: `text-zinc-500 dark:text-zinc-400` — copy: `0pts (tied)`
- `delta === null`: `text-zinc-400 dark:text-zinc-500` — copy: `—`

**"No snapshot" engine cell (CONTEXT.md D-10 pattern):** `italic text-zinc-400 dark:text-zinc-500` — copy: `No model snapshot`

**"Held" user cell (CONTEXT.md D-05):** plain text — copy: `Held — no transfer`. Not italic, not muted — it is a real user decision, not an unavailable state.

**Row overflow:** `overflow-x-auto` wrapper div — same as captain regret table.

**No sort controls, no filter controls** — rows always ordered by GW ascending.

### 6. Empty / Loading / Error States

Follow existing BackTab three-guard pattern exactly (Phase 96 UI-SPEC §5).

**Transfer view loading state:**
- Copy: `Loading transfer history…`
- Class: `text-sm text-zinc-500 dark:text-zinc-400 text-center py-8`

**Transfer view empty state (no slim snapshots yet):**
- Copy: `No transfer history yet — data accumulates each GW after this version is deployed.`
- Class: `text-sm text-zinc-500 dark:text-zinc-400 text-center py-8`

**Transfer view error state:**
- Copy: `Failed to load transfer history. Check your connection and refresh.`
- Class: `text-sm text-red-600 dark:text-red-400 py-4`

## Interaction Contracts

### Captain | Transfer Pill Toggle

- Default active view on BackTab mount: **Captain** (CONTEXT.md D-09). Preserves Phase 96 BACK-01 behaviour — user sees exactly what they see today by default.
- Toggle switch: immediate — no transition, no animation. Content area swaps synchronously.
- Toggle state reset: reverts to Captain on component unmount/remount (CONTEXT.md D-09).
- Keyboard: `role="group"` + `aria-label="Backtester view"` + `aria-pressed` per button — matches GwToggle.tsx pattern exactly.
- No URL state — internal `useState<'captain' | 'transfer'>('captain')` only.

### Transfer Regret Chart

- Bars are not clickable — display only.
- Tooltip appears on bar hover via recharts `<Tooltip content={TransferRegretTooltip} />`.
- Zero-line `ReferenceLine` is non-interactive.
- Chart is not scrollable — all settled GWs visible in a single view.

### Transfer Per-GW Rows

- Rows are read-only — no expand, no click action.
- Rows are always ordered by GW ascending — no sort controls.
- No filter controls — all settled GWs are shown including hold GWs (CONTEXT.md D-04).
- Overflow: horizontal scroll wrapper on mobile (`overflow-x-auto`).

### Captain View (unchanged)

- When Captain pill is active, BackTab renders exactly as it does today — no changes to `SeasonSummaryHeader`, `RegretChart`, captain per-GW rows, Chip ROI, or Hit Tracking sections.
- The pill toggle sits above all of this content.

## Accessibility

- Pill toggle buttons: `min-h-[44px]` touch target.
- Pill toggle wrapper: `role="group"` + `aria-label="Backtester view"` + `aria-pressed` per button.
- Transfer chart wrapper: `aria-label="Transfer regret per gameweek"` on the ResponsiveContainer parent div.
- Color meaning supplemented by text labels — delta direction conveyed by text (`+8pts (engine better)`) not color alone. Satisfies WCAG 1.4.1.
- "No model snapshot" placeholder uses `italic` styling in addition to muted color.
- "Held — no transfer" is plain (not italic/muted) — it is a valid user decision row, not a missing-data state.
- Empty/error states: rendered as `<p>` not `aria-live` — no dynamic announcement needed.

## Dark Mode

Every Tailwind class with a color implication must pair a `.dark:` variant. Pattern sourced from existing `BackTab.tsx`:
- `text-zinc-600 dark:text-zinc-400` — secondary body text
- `text-zinc-500 dark:text-zinc-400` — muted/placeholder text
- `text-zinc-400 dark:text-zinc-500` — unavailable/null placeholder text
- `border-zinc-200 dark:border-zinc-700` — borders
- `bg-zinc-50 dark:bg-zinc-800` — chart/card backgrounds
- `bg-white dark:bg-zinc-900` — tooltip backgrounds
- `text-red-600 dark:text-red-400` — engine-better delta, error state
- `text-green-600 dark:text-green-400` — user-better / good-hold delta

Bar fill dark mode: `#f87171` for delta > 0 bars (matches Phase 96 REGRET_RED dark variant); `#22c55e` unchanged for delta < 0 bars.
