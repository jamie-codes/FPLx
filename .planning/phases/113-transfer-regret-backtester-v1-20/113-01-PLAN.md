<objective>
Lay the data-layer foundation for the Transfer Regret Backtester (BACK-02): a Python pipeline module that side-writes a slim per-GW player snapshot to Vercel Blob each run, wired into the existing pipeline/run.py USE_BLOB guard, plus the TypeScript types that downstream API and UI work in Waves 2-3 consume.

Purpose: Without the slim snapshot written at decision time, `/api/decision-history` has no frozen evidence to feed `suggestTransfers()` post-hoc — recommendations would drift retroactively (forbidden per ROADMAP phase note: "do NOT use future GW data for retroactive recommendations"). Without `SlimPlayer` and `TransferRegretEntry` types, Plans 02-04 cannot compile.
Output: One new Python module + one pytest file, one edit to `run.py`, and three type additions to `types.ts`. No runtime UI/API behaviour change yet.
</objective>
