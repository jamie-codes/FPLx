<objective>
Extend `GET /api/decision-history` to return a `transferEntries: TransferRegretEntry[]` array alongside existing captain regret data. The route reads the per-GW slim snapshot from Vercel Blob (written by Plan 01), reconstructs the user's pre-transfer squad from FPL picks + transfers endpoints (D-03), runs `suggestTransfers()` post-hoc, looks up actual realised points via element-summary, computes the signed delta with `computeTransferDelta()` (Plan 02), and assembles one entry per finished GW.

Purpose: This is the integration seam where the snapshot, the engine, the user's FPL data, and the math primitives converge into the data that the UI (Plan 04) consumes. Every behaviour rule from CONTEXT.md D-03 through D-07 lives here — squad reconstruction, hold detection, multi-transfer compression. Security: four ASVS L1 guards must be present (teamId regex, blob pathname exact-match, element-summary SSRF regex, JSON parse try/catch); see `<threat_model>`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → API (`GET /api/decision-history?teamId=...`) | Untrusted query parameter `teamId` crosses into route handler. Existing regex guard `/^\d+$/` MUST be preserved. |
| API → Vercel Blob (`list({ prefix: 'merged_players_slim_gw{N}.json' })`) | Blob pathname is constructed from `gw: number`. Exact-match check `blobs[0].pathname !== filename` prevents prefix-collision / traversal returning unintended objects. |
| API → FPL public endpoints (`/entry/{teamId}/transfers/`, `/entry/{teamId}/event/{gw}/picks/`, `/element-summary/{elementId}/`) | `teamId` already regex-validated. `gw` is a number from FPL bootstrap (trusted). `elementId` for element-summary fan-out comes from blob snapshot and FPL transfers payload (NOT directly user-controlled) but MUST still pass `/^\d+$/` SSRF guard before the fetch URL is constructed (replicate from season-analytics/route.ts). |
| API → suggestTransfers (in-process) | `slimSnapshot` array is parsed from Blob JSON; `try/catch` in `readTransferSlimSnapshot` collapses malformed JSON to `null` → no engine call → entry returns hasSnapshot: false. |
