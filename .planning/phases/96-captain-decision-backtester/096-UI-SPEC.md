## Color

All tokens are CSS custom properties defined in `src/app/globals.css` with `.dark:` Tailwind variants on every element.

| Role | Light Value | Dark Value | Usage |
|------|-------------|------------|-------|
| Dominant (60%) | `--background: #F7F8FC` | `#0a0a0a` | Page background, section wrappers |
| Secondary (30%) | `--surface: #ffffff` / `--surface-elevated: #f3f4f6` | `#111827` / `#1f2937` | Chart container, tooltip background, table row hover |
| Accent positive (10%) | `--color-positive: #22c55e` | `#22c55e` | Bars BELOW zero axis (user beat model), positive delta cells, win-count stat |
| Accent negative (reserved) | `--color-negative: #ef4444` | `#ef4444` | Bars ABOVE zero axis (model was better, user lost pts), loss-count stat, error state text |
| Muted / secondary text | `--muted: #6b7280` | `#9ca3af` | Empty-state copy, placeholder text, axis tick labels, "No snapshot" placeholder |
| Border | `--border: #e5e7eb` | `#374151` | Chart container border, table cell dividers |

Accent reserved for:
- `color-positive` (#22c55e): regret bars where `regret < 0` (user beat model), "You won" count in season summary, positive delta text in rows.
- `color-negative` (#ef4444): regret bars where `regret > 0` (model was better), "Model better" count in season summary, error state messages.

No second semantic color for destructive actions — Phase 96 has no destructive UI actions.

Source: tokens from `globals.css`; color semantics from CONTEXT.md D-06 (positive regret = red above zero, negative regret = green below zero).

## Component Inventory

### 1. AccuracyTab Sub-Tab Nav

**Pattern:** Reuse `SetPieceViewToggle` pill pattern (Phase 95) extended to 3 options.

```
type AccuracySubTab = 'summary' | 'calibration' | 'back'
```

**Implementation:** New `AccuracySubTabNav` component inline in `AccuracyTab.tsx`, following `SetPieceViewToggle` structure exactly:
- Wrapper: `role="group"` `aria-label="Accuracy section"` `flex rounded overflow-hidden border border-zinc-300 dark:border-zinc-600`
- Each button: `px-3 py-2 sm:py-1 text-sm font-medium transition-all cursor-pointer active:scale-95 min-h-[44px] sm:min-h-0`
- Active: `bg-zinc-900 dark:bg-white text-white dark:text-zinc-900`
- Inactive: `bg-white dark:bg-zinc-800 text-zinc-700 dark:text-zinc-300 hover:bg-zinc-50 dark:hover:bg-zinc-700`

Labels: "Summary" | "Calibration" | "Back"

State: `useState<AccuracySubTab>('summary')` inside `AccuracyTab`. Resets to `'summary'` on re-mount (D-03/D-04).

Placement: Immediately after `{panel}` (DataHealthPanel), before tab content area. Full-width on mobile, natural-width on desktop.

### 2. BackTab Season Summary Header

**Structure:** Single `<div>` with flex layout, renders above the chart.

Two lines of content:
- Line 1 (display): `Total captain regret: {N}pts across {N} GWs` — `text-xl font-semibold` with color indicating net direction (positive total = `text-red-600 dark:text-red-400`, negative total = `text-green-600 dark:text-green-400`, zero = `text-zinc-600 dark:text-zinc-400`)
- Line 2 (body): `Model better: {N} GWs | You won: {N} GWs | Tied: {N} GWs` — `text-sm text-zinc-600 dark:text-zinc-400` with inline colored spans for each count: model-better in `text-red-600 dark:text-red-400`, you-won in `text-green-600 dark:text-green-400`, tied in `text-zinc-500 dark:text-zinc-400`

Wrapper: `mb-4 space-y-1`

### 3. Regret Bar Chart

**Library:** Recharts `BarChart` (not `ComposedChart` — pure bar data, zero composition needed). Already imported in `AccuracyTab.tsx`.

**Container:** `ResponsiveContainer width="100%" height={288}` inside chart wrapper div: `rounded border border-zinc-200 dark:border-zinc-700 bg-zinc-50 dark:bg-zinc-800 px-2 py-3 relative mb-4`

**Axes:**
- XAxis: `dataKey="gw"` type `"number"`, ticks = available GW numbers, `tickFormatter={(v) => \`GW${v}\`}`, `tick={{ fontSize: 12, fill: 'currentColor' }}`, `axisLine={false}`, `tickLine={false}`
- YAxis: numeric (captain points), `tickFormatter={(v) => v >= 0 ? \`+${v}\` : \`${v}\`}`, `tick={{ fontSize: 12, fill: 'currentColor' }}`, `axisLine={false}`, `tickLine={false}`, `width={40}`

**Zero baseline:** `ReferenceLine y={0}` `stroke="rgba(161,161,170,0.5)"` `strokeWidth={1}` — the key visual landmark (from CONTEXT.md D-06, ROADMAP)

**Bar fill:** Conditional per entry using `Cell` from recharts:
- `regret > 0` (model better, user lost): `fill="#ef4444"` (light) / `fill="#f87171"` (dark — slightly lighter for dark mode contrast)
- `regret < 0` (user won): `fill="#22c55e"`
- `regret === 0` (tied): `fill="rgba(161,161,170,0.5)"`

**Tooltip:** Custom `RegretTooltip` component — same structure as `CalibrationTooltip`. Shows: GW number, user's captain (name + pts×2), model's ceiling (name + pts×2), regret value with signed label. Wrapper: `rounded border border-zinc-200 dark:border-zinc-700 bg-white dark:bg-zinc-900 px-3 py-2 text-xs shadow-sm`.

**Animation:** `isAnimationActive={false}` — matches existing AccuracyTab chart convention.

### 4. Per-GW Detail Rows

**Structure:** `<table>` using existing locked classes from AccuracyTab: `TABLE_CLS`, `TH_CLS`, `TR_CLS`, `TD_CLS`. Do NOT redefine these — import or colocate.

**Columns:**
| Column | Content | Width hint |
|--------|---------|------------|
| GW | "GW{N}" | narrow, `w-12` |
| Your captain | Player name + `(Xpts)` | medium |
| Model pick | Player name + `(Xpts)` or "No snapshot" placeholder | medium |
| Regret | Signed value + label | narrow, `text-right` |

**Regret cell rendering:**
- `regret > 0`: `text-red-600 dark:text-red-400` — copy: `+{N}pts (model better)`
- `regret < 0`: `text-green-600 dark:text-green-400` — copy: `−{N}pts (you beat it)`
- `regret === 0`: `text-zinc-500 dark:text-zinc-400` — copy: `0pts (tied)`

**"No snapshot" cell (D-10):** `text-zinc-400 dark:text-zinc-500 italic` — copy: `No model snapshot`

**Authenticated picks unavailable (SC-5):** Actual captain column shows `text-zinc-400 dark:text-zinc-500 italic` — copy: `Log in to see`. Regret column shows `—` in `text-zinc-400 dark:text-zinc-500`. Never blank, never throws.

**Row overflow:** `overflow-x-auto` wrapper div — same as VersionHistoryTable.

### 5. Empty / Loading / Error States (D-11 + SC-5)

All three-guard patterns follow existing AccuracyTab lines 1001–1033 exactly.

**Empty state (zero data):**
- No loading skeleton.
- Renders: `<p className="text-sm text-zinc-500 dark:text-zinc-400 text-center py-8">` containing D-11 copy (see Copywriting Contract below).

**Loading state (hook in-flight):** BackTab itself renders nothing while `useDecisionHistory` `isLoading` is true — BackTab's parent (AccuracyTab) already shows a loading indicator at the section level. BackTab can render a single `<p className="text-sm text-zinc-500 dark:text-zinc-400 text-center py-8">Loading captain history…</p>`.

**Error state:** `<p className="text-sm text-red-600 dark:text-red-400 py-4">` — see Copywriting Contract.

## Interaction Contracts

### AccuracyTab Sub-Tab Nav

- Default active tab on mount: **Summary** (D-03).
- Tab switch: immediate — no transition, no animation. Content swaps synchronously.
- Tab state reset: reverts to Summary on component unmount/remount (D-04).
- Keyboard: standard `role="group"` + `aria-pressed` pattern (consistent with GwToggle, PresetToggle, EOModeToggle).
- No URL state — internal `useState` only (D-04).

### BackTab Chart

- Bars are not clickable — display only.
- Tooltip appears on bar hover (recharts default `<Tooltip content={RegretTooltip} />`).
- Zero-line `ReferenceLine` is non-interactive.
- Chart is not scrollable — all GWs visible in a single view (up to 38 bars at ~7px width each in a 600px container — fits without scroll).

### BackTab Detail Rows

- Rows are read-only — no expand, no click action.
- Table is sortable? **No** — rows are always ordered by GW ascending (chronological). No sort controls.
- Table is filterable? **No** — all GWs shown, pre-deployment rows with "No model snapshot" are included in-order.
- Overflow: horizontal scroll wrapper on mobile.

### localStorage Ring Buffer

- Not visible in UI — internal hook concern. No UI affordance for clearing cache.
- Cache-first load: chart renders from cached data immediately; hook refreshes in background (standard TanStack Query staleTime pattern).

## Accessibility

- All interactive elements (sub-tab buttons): `min-h-[44px]` touch target.
- Sub-tab nav: `role="group"` + `aria-label="Accuracy section"` + `aria-pressed` per button.
- Chart wrapper: `aria-label="Captain regret per gameweek"` on the `ResponsiveContainer` parent div.
- Color meaning supplemented by text labels — regret direction conveyed by text (`+8pts (model better)`) not color alone. Satisfies WCAG 1.4.1.
- Empty/error states: rendered as `<p>` not `aria-live` — no dynamic announcement needed (user navigated to tab intentionally).
- "No model snapshot" and "Log in to see" placeholders use `italic` styling in addition to muted color.

## Dark Mode

Every Tailwind class with a color implication must pair a `dark:` variant. Pattern sourced from existing AccuracyTab:
- `text-zinc-600 dark:text-zinc-400` — secondary body text
- `text-zinc-500 dark:text-zinc-400` — muted/placeholder text
- `border-zinc-200 dark:border-zinc-700` — borders
- `bg-zinc-50 dark:bg-zinc-800` — chart/card backgrounds
- `bg-white dark:bg-zinc-900` — tooltip backgrounds
- `text-red-600 dark:text-red-400` — negative/loss values
- `text-green-600 dark:text-green-400` — positive/win values
- Bar fill for dark mode: `#f87171` (red-400 equivalent) for above-zero bars; `#22c55e` stays same for below-zero bars.
