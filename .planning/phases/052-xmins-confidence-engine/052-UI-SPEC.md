## The Only UI Change in This Phase

### MinsRiskBadge — new optional `mins60Prob` prop

**File:** `src/components/shared/MinsRiskBadge.tsx`

**Change:** Add optional `mins60Prob?: number` prop to `MinsRiskBadge`. When the prop
is present, the native HTML `title` attribute on the badge `<span>` changes format.
When the prop is absent, tooltip is unchanged (backward-compatible).

#### Tooltip String Contract

| Condition | Tooltip format | Example |
|-----------|---------------|---------|
| `mins60Prob` is `undefined` | `"<Label>: <existing description>"` | `"Nailed: high start probability (≥85%)"` — unchanged |
| `mins60Prob` is a number | `"<Label> — <X>% chance 60+ min"` | `"Nailed — 94% chance 60+ min"` |

**Format rules:**
- Separator: ` — ` (space, em dash, space)
- Label: use `config.label` from `BADGE_MAP` — title-cased as stored (`"Nailed"`, `"Likely start"`, `"Rotation risk"`, `"Cameo"`)
- Percentage: `Math.round(mins60Prob * 100)` — integer, no decimal places
- Suffix: `% chance 60+ min` — exact literal string, no trailing punctuation
- When `mins60Prob === 0`: renders `"<Label> — 0% chance 60+ min"` — do not suppress
- When `mins60Prob` rounds to 100: renders `"<Label> — 100% chance 60+ min"` — acceptable

**Tooltip mechanism:** Native HTML `title` attribute on the `<span>` — unchanged. No
Radix tooltip, no custom tooltip overlay introduced in this phase.

## Copywriting Contract

This phase introduces one new string pattern — the conditional tooltip. No other
copy changes.

| Element | Copy |
|---------|------|
| Tooltip — nailed, with prob | `"Nailed — <X>% chance 60+ min"` |
| Tooltip — likely_start, with prob | `"Likely start — <X>% chance 60+ min"` |
| Tooltip — rotation_risk, with prob | `"Rotation risk — <X>% chance 60+ min"` |
| Tooltip — cameo, with prob | `"Cameo — <X>% chance 60+ min"` |
| Tooltip — any bucket, without prob | Unchanged existing strings (e.g., `"Nailed: high start probability (≥85%)"`) |
| Primary CTA | None — this phase has no user-initiated actions |
| Empty state | Not applicable — badge renders null for `undefined`/`injured` (unchanged) |
| Error state | Not applicable — no network call; field is optional with graceful fallback |
| Destructive confirmation | None — no destructive actions in this phase |

**Copywriting rules:**
- Label casing: use `config.label` verbatim from `BADGE_MAP` (e.g., `"Likely start"` not `"Likely Start"`)
- Percentage: integer only, computed as `Math.round(mins60Prob * 100)`
- Suffix: `% chance 60+ min` — exact, no variation
- Separator: ` — ` (space + U+2014 em dash + space)

Source: D-09 from `052-CONTEXT.md`.
