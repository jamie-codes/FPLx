## Component Specification

### CalibrationHealthIndicator

**File:** `src/components/squad/CalibrationHealthIndicator.tsx` (new, ~30 LOC)

**Props:**
```ts
interface CalibrationHealthIndicatorProps {
  data: AccuracyBacktest
}
```

**Guard — render nothing:**
- `!data.calibration?.by_position?.all` — absent or undefined (legacy cache pre-Phase 63)
- `data.calibration.by_position.all.length === 0` — empty array (position pool < 50)

In both cases: return `null`. No "unavailable" fallback text. Silent omission per CONTEXT.md D-12.

**Guard — cold-start override (checked before tier logic):**
- When `data.gws_covered.length < 3`:
  - Render the row but replace the status sentence with: `"Calibration evidence will appear after 3+ completed GWs."`
  - No tier badge rendered in cold-start case.

**Tier logic (when guards pass and not cold-start):**
```
buckets = data.calibration.by_position.all
maxDeviation = max(|b.actual_rate - b.bucket_mid| for b in buckets)
N = Math.round(maxDeviation * 100)  // percentage points
M = buckets.length                   // decile count

tier:
  maxDeviation < 0.05  → "good"
  maxDeviation <= 0.10 → "fair"
  maxDeviation > 0.10  → "poor"
```

**Status sentence format (locked by CONTEXT.md D-11):**
`"Calibration: [tier] — predicted vs actual within [N]pp across [M] deciles"`

Example: `"Calibration: good — predicted vs actual within 3pp across 4 deciles"`

**Layout:**
- Outer wrapper: `flex items-center gap-3 py-3 px-4 border-t border-zinc-200 dark:border-zinc-700 bg-white dark:bg-zinc-900`
- Label: `<span className="text-xs text-zinc-400 dark:text-zinc-500 shrink-0">Model health</span>`
- Tier badge (when not cold-start): `<span className="text-xs font-semibold rounded px-2 py-0.5 {tier-color-classes}">{tier}</span>`
- Status sentence: `<span className="text-sm text-zinc-700 dark:text-zinc-300">{sentence}</span>`
- Cold-start layout: label + cold-start sentence only — no tier badge

**Placement in `DecisionSummaryTab.tsx`:**
- Between the closing `</div>` of the 4-card grid (line 674 area) and `<ProseSummaryBlock>` (line 677)
- No wrapper div needed — the component is self-contained

**Accessibility:**
- `role="status"` on the outer wrapper so screen readers announce calibration health as a live region
- `aria-label="Calibration health: {tier}"` on the tier badge

## States and Interaction Contract

### CalibrationHealthIndicator states

| State | Rendered output |
|-------|----------------|
| `calibration?.by_position?.all` absent or undefined | `null` — silent omission |
| `calibration.by_position.all.length === 0` | `null` — silent omission |
| `gws_covered.length < 3` (cold-start) | Row with label + cold-start sentence, no tier badge |
| Max deviation < 5pp | Row with label + green "good" badge + status sentence |
| Max deviation 5–10pp | Row with label + amber "fair" badge + status sentence |
| Max deviation > 10pp | Row with label + red "poor" badge + status sentence |

### CalibrationSection banner states

| State | Banner shown |
|-------|-------------|
| `gws_covered.length < 3` (cold-start, checked first) | "Calibration evidence will appear after 3+ completed GWs." |
| `chartData.length === 0` (sparse or pool guard, checked second) | "Insufficient data for [position] at this sample size." |
| `chartData.length > 0` | No banner — chart renders normally |

No hover, tooltip, click, or animation on any new component. Display-only.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | None — this phase has no user-triggered actions |
| Health indicator label | `"Model health"` — no colon, no period |
| Health indicator status (good) | `"Calibration: good — predicted vs actual within {N}pp across {M} deciles"` |
| Health indicator status (fair) | `"Calibration: fair — predicted vs actual within {N}pp across {M} deciles"` |
| Health indicator status (poor) | `"Calibration: poor — predicted vs actual within {N}pp across {M} deciles"` |
| Health indicator cold-start | `"Calibration evidence will appear after 3+ completed GWs."` |
| Empty chart banner (updated) | `"Insufficient data for {positionLabel(position)} at this sample size."` |
| Cold-start chart banner | `"Calibration evidence will appear after 3+ completed GWs."` |
| Empty state heading | Not applicable — absent calibration is silent omission |
| Error state | Not applicable — absent data silently omits the component |
| Destructive confirmation | None — no destructive actions |

Notes:
- Tier labels ("good", "fair", "poor") are always lowercase — they are data values, not sentence starts.
- The em-dash in the status sentence is a true en-dash (`—`, `U+2014`) for readability.
- "pp" (percentage points) is always lowercase, no space between number and unit: e.g. `"3pp"` not `"3 pp"`.
- "GWs" (gameweeks) uses the project-established abbreviation — consistent with existing text throughout the app.
