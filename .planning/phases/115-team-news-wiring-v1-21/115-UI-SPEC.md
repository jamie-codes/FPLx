## Component Specifications

### NEWS-01: Staleness Suppression Gate in NewsBanner

- **File:** `src/components/news/NewsBanner.tsx`
- **Change:** After `const severity = computeNewsSeverity(...)` (line 34) and before `if (severity === 'none') return null` (line 35), insert the staleness guard.
- **Guard logic:**
  ```tsx
  const isStale = (newsAdded?: string): boolean =>
    newsAdded ? Date.now() - new Date(newsAdded).getTime() > 14 * 24 * 60 * 60 * 1000 : false
  if (severity === 'zinc' && isStale(news_added)) return null
  ```
- **Visual contract:** When suppressed, `NewsBanner` renders `null` — zero visual output. No placeholder, no greyed-out text, no tooltip.
- **States:**

  | Severity | news_added age | Rendered |
  |----------|---------------|----------|
  | red | any | Always rendered (never suppressed) |
  | amber | any | Always rendered (never suppressed) |
  | zinc | < 14 days | Rendered as `text-zinc-500 dark:text-zinc-400` with ℹ icon |
  | zinc | >= 14 days | `null` — nothing rendered |
  | none | any | `null` — existing guard unchanged |

- **`computeNewsSeverity()` signature:** Unchanged. Pure severity classifier stays date-unaware (D-01).
- **`news_added` prop:** Already declared in `NewsBannerProps` interface, currently unused — this phase activates it. No interface change needed.

Source: CONTEXT.md D-01, D-02, D-03; `src/components/news/NewsBanner.tsx` lines 11–42.

### NEWS-02: NewsBanner in CaptainPicksPanel CandidateRow

- **File:** `src/components/captaincy/CaptainPicksPanel.tsx`
- **Change:** In `CandidateRow`, inside the first flex div (`className="flex items-center gap-1.5 sm:flex-1 flex-wrap"`, line 120), append `<NewsBanner>` after `{mcLabel && <McLabel .../>}` (line 131).
- **Import:** Add `import { NewsBanner } from '@/components/news/NewsBanner'` at the top of file.
- **Placement:**
  ```tsx
  {mcLabel && <McLabel label={mcLabel.label} value={mcLabel.value} />}
  <NewsBanner
    news={candidate.news ?? ''}
    news_added={candidate.news_added}
    chance_of_playing_next_round={candidate.chance_of_playing_next_round}
  />
  ```
- **Visual contract:** `NewsBanner` renders inline inside the existing `flex flex-wrap` div. When present, it appears to the right of any MC label badge, on the same line if space permits, wrapping to a new line otherwise. No separate container, no border, no background — mirrors the `OpportunityCostTable` pattern.
- **Overflow handling:** `flex-wrap` already on the div (pre-existing `gap-1.5 sm:flex-1 flex-wrap`) — news text wraps gracefully when the row is narrow. No additional layout work.
- **`candidate` type:** `MergedPlayer` — already has `news: string`, `news_added?: string`, `chance_of_playing_next_round?: number | null` (from CONTEXT.md canonical refs).
- **States:**

  | Condition | Visual |
  |-----------|--------|
  | No news (`news === ''` or `news` falsy) | `null` — nothing rendered, row unchanged |
  | Zinc severity, fresh (< 14 days) | ℹ + news text in `text-zinc-500 dark:text-zinc-400 text-xs`, inline after badges |
  | Zinc severity, stale (>= 14 days) | `null` — suppressed by NEWS-01 guard |
  | Amber severity (any age) | ⚠ + news text in `text-amber-600 dark:text-amber-400 text-xs`, inline after badges |
  | Red severity (any age) | ⚠ + news text in `text-red-600 dark:text-red-400 text-xs`, inline after badges |
  | Feature flag `useNewsFlagEnabled()` = false | `null` — existing flag guard in NewsBanner suppresses output |

Source: CONTEXT.md D-04; `src/components/captaincy/CaptainPicksPanel.tsx` lines 85–163; `src/components/transfers/OpportunityCostTable.tsx` lines 129–141 (reference pattern).
