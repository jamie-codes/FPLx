    GREEN phase — implement computeVerdicts:

    Function signature:
    ```typescript
    export type Verdict = 'buy' | 'hold' | 'sell'
    export function computeVerdicts(
      squadPicks: SquadPick[],
      allPlayers: ScoredPlayer[],
    ): Map<number, Verdict>
    ```

    Algorithm:
    1. Build a Map<number, ScoredPlayer> from allPlayers (keyed by id)
    2. Compute position averages from ALL allPlayers:
       - For each element_type (1,2,3,4): average gem_score across all players at that position
       - If no players at a position, use 0.5 as fallback
    3. For each squadPick where position < 12 (starting XI only):
       - Look up the player in the allPlayers map by pick.element
       - Look up positionAvg for that player's element_type
       - Classify:
         - Buy: gem_score > positionAvg (above average for position)
         - Sell: gem_score < positionAvg * 0.90 (more than 10% below average)
         - Hold: everything else (within 0-10% below average)
       - Set verdicts.set(pick.element, verdict)
    4. Return the verdicts Map

    Threshold constants (exported for test visibility):
    ```typescript
    export const BUY_THRESHOLD = 1.0    // gem_score > positionAvg * 1.0
    export const SELL_THRESHOLD = 0.90   // gem_score < positionAvg * 0.90
    ```

    REFACTOR: Extract positionAverages computation into a helper `computePositionAverages(allPlayers)` for reuse by captaincy-engine.ts (Plan 02).
