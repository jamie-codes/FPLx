    GREEN phase — implement computeCaptaincyCandidates:

    Algorithm:
    1. Build Map<number, ScoredPlayer> from allPlayers (keyed by id)
    2. Compute position averages from ALL allPlayers (same logic as recommend.ts):
       - For each element_type (1,2,3,4): average gem_score across all players at that position
       - Fallback to 0.5 if no players at a position
    3. Filter squadPicks to starting-XI only (position < 12)
    4. For each starting-XI pick:
       - Look up player from allPlayers map by pick.element
       - Skip if not found, or proj_pts_1gw <= 0, or mins_risk === 'injured'
       - Compute projected_captain_pts = proj_pts_1gw * 2
       - Classify captain_type:
         - 'safe' if mins_risk === 'nailed' AND gem_score >= positionAvg for player's element_type
         - 'upside' for everything else
       - Create CaptaincyCandidate object
    5. Sort by projected_captain_pts descending
    6. Return top N (default 5)

    Note: The position average computation is identical to recommend.ts. If recommend.ts exports a `computePositionAverages` helper (see Plan 01), import and reuse it. If Plan 01 hasn't run yet, implement inline — the executor for Plan 03 will deduplicate if needed.
