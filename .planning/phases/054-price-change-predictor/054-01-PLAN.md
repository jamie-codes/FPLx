Public function signature (price_changes.py):
```python
def compute_price_change_predictions(
    bootstrap: dict,
    prev_snapshot: dict,
) -> tuple[dict, dict]:
    """Returns (predictions_payload, current_snapshot).

    predictions_payload shape:
      {
        'generated_at': str,            # ISO 8601 UTC
        'current_gw': int,              # bootstrap['events']['current']['id'] or 0
        'snapshot_days': int,           # count of distinct ISO dates across all per-player date lists
        'predictions': list[dict],      # [] on cold start
      }

    Each prediction dict shape:
      {
        'player_id': int,               # element['id']
        'name': str,                    # element['web_name']
        'team': str,                    # team_short_name lookup from bootstrap['teams']
        'now_cost': int,                # element['now_cost'] (tenths of £1m)
        'direction': 'rise' | 'fall' | 'stable',
        'confidence_pct': float,        # 0..100, rounded 2dp
        'eta_days': float,              # >= 0; 0 means "Tonight"
        'cumulative_net': int,
        'selected_by_percent': str,     # FPL string e.g. "12.5"
      }

    current_snapshot shape (per player_id key as str):
      {
        '<player_id>': {
          'cumulative_net': int,
          'last_now_cost': int,         # used to detect cost_change_event reset
          'velocity_history': list[int],# last N daily deltas for avg
          'dates': list[str],           # ISO dates the player was seen on
        },
        ...
      }
    """
```

Threshold and confidence formula (D-03 verbatim):
```python
ownership = float(element.get('selected_by_percent', '0') or '0')
threshold = max(1.0, ownership * 10)
confidence_pct = round(min(1.0, abs(cumulative_net) / threshold) * 100, 2)
if avg_velocity > 0:
    eta_days = max(0.0, (threshold - abs(cumulative_net)) / avg_velocity)
else:
    eta_days = 999.0  # sentinel for "no movement"
```

Direction rule (D-03 verbatim):
```python
if abs(cumulative_net) < threshold * 0.05 or confidence_pct < MIN_CONFIDENCE_FOR_DIRECTION:
    direction = 'stable'
elif cumulative_net > 0:
    direction = 'rise'
else:
    direction = 'fall'
```
