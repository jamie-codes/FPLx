<objective>
Land the Phase 133 pipeline foundation: a new pipeline/price_baseline.py module that captures per-player now_cost from bootstrap into price_baseline.json on Vercel Blob, guarded by an idempotency check that mirrors archive_season.py. Wire it into pipeline/run.py as an unconditional, non-fatal call so the baseline is captured exactly once during the season-end window.

Purpose: PRST-01 requires a write-once price baseline that the API can diff against next-season bootstrap prices. Capturing now_cost across all 700+ elements before FPL resets cost_change_start at the season turnover is the only way to produce cross-season deltas. The blob guard ensures subsequent runs cannot overwrite the baseline once written.

Output: One new Python module (price_baseline.py), one new pytest file (test_price_baseline.py), and a 4-6 line edit to run.py adding the import + try/except call.
</objective>
