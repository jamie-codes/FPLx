## Component Inventory

### 1. SetPieceTakerPanel

**Purpose**: SP-01 — Dedicated panel listing penalty taker, direct FK taker, and corner taker for each Premier League team.

**Structure:**
```
<section> (space-y-4 wrapper)
  <h2> "Set-Piece Takers" — text-lg font-semibold mb-2
  <div> (grid of team cards, 1 column mobile, 2 columns sm:, 3 columns lg:)
    <TeamSetPieceCard> per team
      - Team name: text-sm font-semibold mb-1
      - Three rows:
        - "Penalties: {player name}" — text-sm
        - "Direct FK: {player name}" — text-sm
        - "Corners: {player name}" — text-sm
      - If any taker changed since last run: inline "Changed" badge (amber, text-xs)
```

**States:**
- **Loading**: `<p className="text-zinc-500 dark:text-zinc-400">Loading set-piece data...</p>` — centred, py-8
- **Empty**: `<p>No set-piece data available. Pipeline may not have run yet.</p>` — text-sm text-zinc-500 py-4
- **Error**: See Copywriting Contract
- **Changed taker**: amber "Changed" badge inline after taker name; visible for all takers that changed vs previous run
- **No change**: No badge — renders cleanly without visual noise

**Placement**: New tab entry in the main tab list. Tab label: "Set Pieces". Inserted between "Club Form" and "Value Gems" on desktop tab bar; between "Form" and "Values" on mobile nav (label: "SP"). See Copywriting Contract for exact labels.

**Card padding**: p-3 (12px — between sm and md, closest multiple of 4 that matches card density)
**Card border**: `rounded border border-zinc-200 dark:border-zinc-700 bg-white dark:bg-zinc-900`
**Grid gap**: gap-3

### 2. SetPieceChangeAlert

**Purpose**: SP-02 — Inline alert within SetPieceTakerPanel when one or more taker changes are detected since the previous pipeline run.

**Structure:**
```
<div className="rounded border border-amber-400 bg-amber-50 dark:bg-amber-950 p-4 text-sm text-amber-800 dark:text-amber-200 mb-4">
  <span className="font-semibold">Set-piece changes detected</span> — {N} taker order change(s) since the last pipeline run. Updated rows are marked below.
</div>
```

**Visibility rules:**
- Shown at top of SetPieceTakerPanel, above the grid of team cards
- Shown only when at least one taker field differs between current and previous pipeline run
- Hidden entirely when no changes detected — no empty state for this alert
- Not dismissible — informational only, resolves on next pipeline run with no changes

**Pattern source**: Matches `TransferPanel.tsx` chip-warning amber pattern exactly.

### 3. LandscapeTip

**Purpose**: MOB-LS-01 — Subtle tip shown on Gems and DefCon tabs on mobile portrait orientation.

**Structure:**
```
<div className="sm:hidden rounded border border-zinc-300 dark:border-zinc-600 bg-zinc-100 dark:bg-zinc-800 px-4 py-2 text-xs text-zinc-600 dark:text-zinc-300 mb-2">
  Rotate to landscape for the full table.
</div>
```

**Visibility rules:**
- Rendered only when: (a) current tab is Gems or DefCon, AND (b) `window.innerWidth < 640` (mobile breakpoint matching existing `isMobile` pattern), AND (c) device is in portrait orientation (`window.screen.orientation.type` includes "portrait" OR `window.innerHeight > window.innerWidth`)
- Uses `sm:hidden` to prevent rendering on desktop (defence-in-depth alongside JS check)
- Positioned at top of tab content, below filters/toolbar, above the table
- No dismiss button — re-evaluates on each orientation change event via `orientationchange` listener

**Mobile detection pattern**: Reuse the existing `isMobile` state pattern from `GemTable.tsx` and `DefConTables.tsx` (`window.innerWidth < 640` via resize listener).

## Interaction Contracts

### Tab navigation (new "Set Pieces" tab)

- Desktop tab bar (`hidden sm:flex`): Add "Set Pieces" button using identical className pattern as existing tabs. Insert after "Club Form" tab, before "Value Gems" tab.
- Mobile nav (`MobileNav.tsx`): Add `{ id: 'set-pieces', label: 'SP' }` to `TABS` array. Position after `club-form`, before `value-gems`. Label truncated to "SP" to fit the 6-tab flex layout.
- Tab type union: Add `'set-pieces'` to `Tab` type in `page.tsx`.

### Changed badge interaction

- The "Changed" badge (`text-xs font-normal rounded px-2 py-1 bg-amber-100 dark:bg-amber-900 text-amber-800 dark:text-amber-200`) is non-interactive — no click, hover, or expand behaviour.
- It carries a `title` attribute: `"Taker order changed since last pipeline run"` for accessibility.

### Landscape tip lifecycle

- Shown on mount if portrait + mobile + correct tab
- Hides when device rotates to landscape (orientation change listener)
- Re-shows if device rotates back to portrait
- No user-dismissible mechanism — intentionally passive
