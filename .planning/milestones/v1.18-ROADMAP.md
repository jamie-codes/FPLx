### Phase 105: NLP-02 Per-Player LLM Insight Route, Hook & UI

**Goal**: Users can request an on-demand Claude-generated explanation for any player via an explicit "Get AI insight" button — grounded in structured data with a name-whitelist guardrail and two-tier cache, so the model can never invent statistics or auto-fire on row mount
**Depends on**: Phase 102 (MC fields non-null), Phase 104 (rejection reasons + fragility tier wired)
**Requirements**: NLP-02
**Plans**: 3 plans (Wave 0 + Wave 1 + Wave 2)

- [x] 105-01-PLAN.md — Wave 0: RED-phase test scaffolding (route, hook, component, OCT additions, GemTable test stubs)
- [x] 105-02-PLAN.md — Wave 1: core infrastructure (`PlayerInsight` types, `/api/player-insight` route, `usePlayerInsight` mutation hook, `PlayerInsightSection` component)
- [x] 105-03-PLAN.md — Wave 2: integration (`TransferPanel` → `OpportunityCostTable` → `PlayerMoveCell` gw threading, GemTable expand-row insertion, full-suite phase gate, human UAT checkpoint)

**Key decisions:**
- Node.js runtime only — `export const runtime = 'edge'` explicitly forbidden (`@anthropic-ai/sdk` SSE parsing fails on Edge per anthropics/anthropic-sdk-typescript#292)
- `useMutation` not `useQuery` — no auto-refetch; trigger on demand only; never from `useEffect`
- Two-tier cache: `playerInsight:{id}:gw{N}` in localStorage + `player_insights/gw{N}/element_{id}.json` in Vercel Blob (`allowOverwrite: true`, `addRandomSuffix: false`)
- Cache key includes `pipeline_run_date` so stale prose never appears alongside fresh stats
- Two-attempt name-whitelist guardrail; fallback to structured `reasons[]` on both failures
- `maxDuration = 30` on route handler; two-attempt guardrail caps exposure if attempt-1 fails validation
- `PlayerInsightSection` 5 states: idle / loading / error / guardrail-failed / insight
- `gw` prop threading: `TransferPanel.nextGw` → `OCT` → `PlayerMoveCell`; GemTable derives `insightGw = (lastGwActualGwN ?? 0) + 1`
- OCT test `gw prop threaded` assertion uses `vi.mocked().mock.calls[0][0].gw` — `expect.anything()` does not match `undefined` second arg in Vitest
- DecisionSummaryTab auto-fix: `gw={nextGw ?? 0}` added during Wave 2 TypeScript gate
