## Milestone Summary

**Key Decisions:**
- Twitter/X scraping excluded from SCRAPER-02 — GitHub Actions Azure IPs permanently blocked; RSS covers same signal
- Season Review A-D grade framed as checklist (captain EV rate 40% + hit break-even 35% + chip ROI 25%); methodology note required to distinguish luck from process skill (C-06 pitfall)
- `buildPreSeasonSquad()` new function, never reuses `buildOptimalSquad()` — greedy cold-start on 700+ players fails at 100m without backtracking; ILP fallback via PuLP (C-01)
- `archive_season.py` time-sensitive — ships before GW38 closes; data permanently lost after season rollover (no recovery path)
- IS_OFF_SEASON detection via `not any(e.get('is_current') for e in events)` — covers mid-season BGW false-positive risk

**Issues Resolved:**
- POL-01/02 (TRT-06/TRT-02): ChipToggle hardcoded null and wrong column label in RouteTreeTab — deferred from Phase 60 for 14 phases
