**layout.tsx changes:**

1. Add `import type { Viewport } from 'next'` at the top, alongside the existing `import type { Metadata } from "next"`.

2. Add a new `viewport` export BEFORE the existing `metadata` export:
```typescript
export const viewport: Viewport = {
  width: 'device-width',
  initialScale: 1,
  viewportFit: 'cover',
}
```

This is a Server Component export — NOT placed inside the `metadata` object. The `viewportFit: 'cover'` value is critical: without it, `env(safe-area-inset-bottom)` evaluates to `0` and MOB-NAV-03 has no effect.

Do NOT use the deprecated `metadata.viewport` string pattern. Do NOT add `maximumScale: 1` or `userScalable: false` — these break accessibility (per research anti-patterns).

**globals.css changes:**

3. Add the `.nav-safe-bottom` utility class AFTER the existing `body` rule block:
```css
.nav-safe-bottom {
  padding-bottom: env(safe-area-inset-bottom);
}
```

This class will be applied to the MobileNav component in Task 2. Using a custom CSS class instead of Tailwind arbitrary value `pb-[env(safe-area-inset-bottom)]` for readability.
