### Phase 107: NLP-02 Prompt Caching

**Goal**: Add `cache_control: ephemeral` to the `/api/player-insight` system prompt so Anthropic prompt caching activates when the prompt exceeds 1024 tokens, and log cache hit metrics in Vercel
**Depends on**: Phase 105 (NLP-02 route)
**Plans**: 1 plan

Plans:

- [x] 107-01-PLAN.md — CACHE-01 + CACHE-02: wrap `buildSystemPrompt()` return as `TextBlockParam[]` with `cache_control: ephemeral`; log `cache_creation_input_tokens` / `cache_read_input_tokens` after each successful Claude call

**Key decisions:**
- Renamed `system` (string) to `systemText` then wrapped as `TextBlockParam[]` to avoid type collision with SDK parameter name
- Cache activation is a structural no-op at ~80 tokens — activates when prompt crosses Anthropic's 1024-token minimum (Phase 108 batch or organic prompt growth)

**Goal**: Pipeline pre-generates Claude insights for the top-20 players by `xPts_1gw` after each daily run, writing to Vercel Blob; UI reads Blob-cached insights transparently before calling Anthropic
**Depends on**: Phase 107 (prompt caching plumbing live)
**Plans**: 3 plans

Plans:

- [x] 108-01-PLAN.md — NLP-BATCH-01: `pipeline/batch_insights.py` — generates 2-3 sentence Claude insights for top-20 players, writes `player_insights/gw{N}/element_{id}.json` to Vercel Blob
- [x] 108-02-PLAN.md — NLP-BATCH-02: `pipeline/run.py` wired with `INSIGHT_BATCH_ENABLED` gate (non-fatal, top-20 selection, fully skipped when unset)
- [x] 108-03-PLAN.md — NLP-BATCH-03: Blob read-before-generate inserted in `/api/player-insight` route — cache hits return pre-generated insights in ~50-150ms with zero Anthropic calls (TDD RED→GREEN, 16/16 tests)

**Key decisions:**
- Cache block inserted before Anthropic client construction (not after userMsg) to satisfy zero-constructor-calls test assertion on cache hit
- `INSIGHT_BATCH_ENABLED` gate defaults to false — defence-in-depth against unintended cost
- Batch covers top-20 players by `xPts_1gw` (status='a' filter, ties broken by `selected_by_percent` desc)

## Milestone Summary

**Key Decisions:**
- NLP-BATCH: batch covers top-20 only — cost-controlled; on-demand covers the rest for cache misses
- Phase 109 graceful-degradation: when ≥80% of the population has MC fields, `calibration_mode` is `'mc'`; missing-MC players fall back to analytical proxy per-player
- Prompt caching is plumbing-only at current prompt size (~80 tokens) — activates automatically as prompt grows or batch increases system prompt size

**Issues Resolved:**
- WR-01/02/03/04 carry-forward backlog (from v1.16) fully cleared
- NLP-BATCH-03 gap: route was not reading pre-generated Blob insights before generating; closed via Plan 03 TDD cycle
- D-11 bug: `maxDeviation` was comparing against `bucket_mid` instead of `predicted_rate` (caused wrong tier in MC mode)

**Issues Deferred:**
- Prompt caching cost savings pending prompt growth above 1024-token Anthropic minimum
- Phase 109 verification of `calibration_mode` in live `accuracy_backtest.json` pending next pipeline run
