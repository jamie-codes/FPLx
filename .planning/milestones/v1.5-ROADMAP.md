## Milestone Summary

**Key Decisions:**
- Navigation consolidated to 3-section hierarchy — addressed 9+ tab overwhelm identified in v1.5 scope definition
- GemTable preset model: 3 named presets (Default/Compact/Analysis) with column-visibility maps, session-persistent via page.tsx state
- Player comparison via native `<dialog>` element — consistent pattern with AuthModal and PlayerPickerModal
- proj_pts model removed (ACC-06): xPts outperformed in 4 of 5 GWs (16.7% vs 9.0% overall hit rate); user confirmed via human-in-the-loop checkpoint

**Issues Resolved:**
- Pre-existing stale captain-picks test assertion (b81c240 had moved CaptainPicksPanel before test update) — fixed in Phase 41
- proj_pts cascade risk across 9+ files managed with partial commit + fresh-session sweep pattern
