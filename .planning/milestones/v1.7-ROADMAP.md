# Milestone v1.7: Decision Assistant

**Status:** ✅ SHIPPED 2026-05-02
**Phases:** 47-51
**Total Plans:** 14 (5+3+2+2+2)

## Overview

v1.7 turned the app from an analytics dashboard into a weekly decision engine — answering "what should I actually do with my team this week?" across transfers, captaincy, chips, and bench. All five phases compose cleanly: each phase's output is consumed by the next, culminating in a single-screen Decision Summary that surfaces all v1.7 signals in priority order.

**Git stats:** 88 commits, 323 files changed, +45,267 / -1,113 lines over 2 days (2026-05-01 → 2026-05-02)

### Phase 51: Weekly Decision Summary

**Goal**: Users see captain recommendation, transfer recommendation, chip timing flag, and risk flags on a single screen in priority order with severity signals — no tab-hopping required
**Depends on**: Phases 47, 48, 49, 50 (composites all preceding v1.7 engines)
**Requirements**: WDS-01, WDS-02, WDS-03, WDS-04, WDS-05
**Plans**: 2 plans (2 waves)

- [x] 051-02: DecisionSummaryTab component (4 cards) + page.tsx Decision sub-tab wiring

**Details:**
- `SeverityLevel = 'HIGH' | 'MEDIUM' | 'LOW'`; `DecisionSeverity` interface (captain/transfer/chip/risk fields)
- Captain rule: `top1 >= 2 * top2 (with top2>0 guard) → HIGH`; else `MEDIUM`
- Transfer/Risk shared rule: `sell|minutes_trap → HIGH`; `sell_soon|fixture_trap → MEDIUM`; else `LOW`
- Chip rule: `(isDGW||isBGW) && hasAvailableChip && hasRecommendedChip → HIGH`; `hasRecommendedChip → MEDIUM`; else `LOW`
