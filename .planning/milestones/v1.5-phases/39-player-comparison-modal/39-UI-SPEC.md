## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), inline badge margin (`ml-1`) |
| sm | 8px | Gap between section columns (`gap-2`), between badges |
| md | 16px | Modal internal padding (`p-4`), horizontal search padding (`px-3 py-2`) |
| lg | 24px | Between data sections inside the modal (`gap-6`) |
| xl | 32px | Not used in this phase |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Modal max-height: `max-h-[85vh]` — 85 viewport-height cap to keep the modal on-screen with scrollable content.
- Mobile touch target for compare button (within mobile action sheet): `min-h-[44px]` — matches existing project mobile tap-target standard.
- Search input font-size: `style={{ fontSize: '16px' }}` inline override (prevents iOS Safari zoom — same fix as `PlayerPickerModal.tsx` line 134).

Source: `PlayerPickerModal.tsx` (p-4, px-3 py-2, max-h-[70vh] pattern), `MinsRiskBadge.tsx` (gap-1 between badges), `PresetToggle.tsx` (min-h-[44px] mobile target).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Modal heading (player names, section titles) | 14px (text-sm) | 600 (font-semibold) | 1.2 |
| Section label / table label row | 12px (text-xs) | 600 (font-semibold) | 1.2 |
| Body / data values (xPts numbers, score integers) | 14px (text-sm) | 400 (font-normal) | 1.5 |
| Badge text (BUY/SELL/DIFF/TRAP/Nailed etc.) | 12px (text-xs) | 400 (font-normal) | 1.2 |

Notes:
- Two weights only: 400 (font-normal) for data values and badges, 600 (font-semibold) for headings and section labels.
- No bold (700) is used inside the modal — consistent with D-09 (no winner highlighting via weight).
- Modal main title uses `text-base font-semibold` (16px, weight 600) — mirrors `PlayerPickerModal.tsx` line 112 heading pattern.

Source: `PlayerPickerModal.tsx` line 112 (`text-base font-semibold`), badge components (all use `text-xs font-normal`), `GemTable.tsx` (`text-sm font-semibold` for table headers).

### Compare Icon Trigger (modified — `src/components/gem-table/columns.tsx`)

The `web_name` column uses `col.accessor('web_name', { cell: ... })` (not `col.display`) to preserve TanStack Table automatic sorting.

Desktop hover-reveal icon inside the `web_name` cell:
```
<div className="relative group/name flex items-center gap-1">
  <span>{row.original.web_name}</span>
  <button
    type="button"
    onClick={(e) => { e.stopPropagation(); onCompare(row.original) }}
    className="opacity-0 group-hover/name:opacity-100 transition-opacity text-zinc-400 hover:text-zinc-700 dark:hover:text-zinc-200 ml-1 text-xs cursor-pointer"
    aria-label={`Compare ${row.original.web_name}`}
  >
    ⊞
  </button>
</div>
```

Icon character: ⊞ (U+229E SQUARED PLUS). Inline Unicode, no icon library.

Visibility: `opacity-0 group-hover/name:opacity-100 transition-opacity` — invisible at rest, appears on cell hover. No layout shift (zero-width icon occupies space via `ml-1 text-xs`).

Source: CONTEXT.md D-01; RESEARCH.md Pattern 2.

On mobile, tapping the player name cell reveals a small inline action sheet below the name. The "Compare" button in the sheet fires `onCompare(player)`. The sheet is controlled by local `useState` in `GemTable`. The tap must `e.stopPropagation()` to prevent row expand.

## Interaction Contract

### Modal lifecycle

| Trigger | Behaviour |
|---------|-----------|
| Hover over player name cell (desktop) | Compare icon (⊞) becomes visible |
| Click compare icon (desktop) | `onCompare(player)` fires; `comparePlayer` set in `page.tsx`; modal opens via `showModal()` |
| Tap player name cell (mobile) | Inline action sheet appears below name |
| Tap "Compare" in action sheet (mobile) | `onCompare(player)` fires; action sheet dismissed; modal opens |
| Tap "✕" in action sheet (mobile) | Action sheet dismissed; no modal open |
| Modal opens | Player A data renders immediately; search input auto-focuses (50ms delay) |
| Type in search | Player list filters in real time; no debounce needed (client-side array) |
| Select Player B from search results | Player B data populates right column; search list collapses |
| Click backdrop | Modal closes; `onClose()` called; `compareOpen` set to false |
| Press Escape key | Native `<dialog>` closes; `close` event listener calls `onClose()` |
| Click ✕ close button | `onClose()` called; modal closes |
| Modal closes | `comparePlayer` state remains (modal can be reopened without losing Player A) |
| Switch to different GemTable row compare | `comparePlayer` updates; Player B search resets to empty |

### Accessibility

- `<dialog>` element: browser-native focus trap, Escape key, `role="dialog"`.
- `aria-label="Compare {player.web_name}"` on the hover icon button.
- `aria-label="Close"` on the ✕ button.
- Compare icon button uses `type="button"` (no form submission).
- Section headings use `<h3>` inside the modal (`<h2>` is the modal title).
- Player A / Player B column headings are `<p>` with `font-semibold`, not landmark headings.
- Search input: no explicit `aria-label` needed — `placeholder` is descriptive; no label element added (mirrors `PlayerPickerModal.tsx` pattern).

### State ownership

| State | Owner | Notes |
|-------|-------|-------|
| `comparePlayer: ScoredPlayer \| null` | `page.tsx` | Set by `handleCompare(player)` callback |
| `compareOpen: boolean` | `page.tsx` | Controlled by `handleCompare` (open) and modal `onClose` (close) |
| `playerB: ScoredPlayer \| null` | `PlayerComparisonModal.tsx` | Local state; resets to null when modal closes |
| `search: string` | `PlayerComparisonModal.tsx` | Local state; resets to '' when modal closes |
| `actionSheetPlayer: number \| null` | `GemTable.tsx` | Local state; the player ID whose action sheet is open on mobile |
