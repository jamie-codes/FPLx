    Create the catch-all FPL proxy at `src/app/api/fpl/[...proxy]/route.ts`. This is the CORS-bypassing server-side proxy that all subsequent phases use to call FPL endpoints from the browser.

    **Critical Next.js 16 detail:** `params` is a `Promise` and MUST be awaited.

    Exact implementation:

    ```typescript
    import type { NextRequest } from 'next/server'

    const FPL_BASE = 'https://fantasy.premierleague.com/api'

    export async function GET(
      request: NextRequest,
      { params }: { params: Promise<{ proxy: string[] }> }
    ) {
      const { proxy } = await params
      const path = proxy.join('/')

      // Forward query string (e.g. ?event=38 for fixtures)
      const url = new URL(request.url)
      const search = url.search

      const upstreamUrl = `${FPL_BASE}/${path}/${search}`

      try {
        const res = await fetch(upstreamUrl, {
          headers: {
            'User-Agent': 'fplx/1.0',
            'Accept': 'application/json',
          },
          next: { revalidate: 0 },
        })

        if (!res.ok) {
          return Response.json(
            { error: 'FPL API error', status: res.status },
            { status: res.status }
          )
        }

        const data = await res.json()
        return Response.json(data)
      } catch (err) {
        return Response.json(
          { error: 'FPL API unreachable', detail: String(err) },
          { status: 502 }
        )
      }
    }
    ```

    URL mapping behavior:
    - `/api/fpl/bootstrap-static` -> `https://fantasy.premierleague.com/api/bootstrap-static/`
    - `/api/fpl/entry/123456/event/38/picks` -> `https://fantasy.premierleague.com/api/entry/123456/event/38/picks/`
    - `/api/fpl/fixtures?event=38` -> `https://fantasy.premierleague.com/api/fixtures/?event=38`

    Error handling: returns JSON `{ error, status }` on upstream 4xx/5xx, returns `{ error, detail }` with 502 if fetch itself fails (network error).
