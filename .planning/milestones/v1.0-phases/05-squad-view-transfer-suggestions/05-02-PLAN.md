  <implementation>
    After all tests are RED (failing), implement `computeTransferSuggestions` in `src/lib/transfer-engine.ts`:

    1. **Chip guard** (lines 1-3 of logic): if activeChip is 'freehit' or 'wildcard', return CHIP_WARNING immediately. Do NOT guard on 'bboost' or '3xc' — those chips do not affect transfers.

    2. **Build squad set**: `const squadIds = new Set(picks.map(p => p.element))` — for O(1) exclusion check.

    3. **Build player lookup**: `const playerMap = new Map(allPlayers.map(p => [p.id, p]))` — cross-reference picks to ScoredPlayer.

    4. **Identify starting XI sell candidates**: `picks.filter(p => p.position >= 1 && p.position <= 11)`, resolved to ScoredPlayer via playerMap, sorted by gem_score ascending.

    5. **For each sell candidate**, find replacements:
       - Filter allPlayers where: `element_type === sell.element_type` AND `!squadIds.has(candidate.id)` AND exists (no additional filter for budget — include all, mark budget_sufficient)
       - Sort by gem_score descending, take top 3
       - Compute: `gem_delta = buy.gem_score - sell.gem_score`
       - Compute: `available_budget = bankBalance / 10 + sell.now_cost / 10`
       - Compute: `approx_cost = buy.now_cost / 10 - sell.now_cost / 10`
       - Compute: `budget_sufficient = buy.now_cost / 10 <= available_budget`
       - Create SingleTransfer for each

    6. **Flatten all suggestions**, sort by gem_delta descending. Within same gem_delta, prefer budget_sufficient=true.

    7. **Save check**: if no suggestion has gem_delta > 0, return SAVE result.

    8. **Multi-transfer combo** (if freeTransfers >= 2):
       - Take best suggestion as first transfer
       - For second transfer: find next best suggestion where `buy.id !== first.buy.id` AND `sell.id !== first.sell.id`
       - Set `two_transfer_combo = [first, second]` (or omit if no valid second exists)

    9. **Return**: `{ type: 'SUGGESTIONS', suggestions: topSuggestions, two_transfer_combo }`

    Test factory: Create `makeScoredPlayer(overrides)` similar to `makeMergedPlayer` from gem-score.test.ts, but extending with gem_score and dimension scores.
