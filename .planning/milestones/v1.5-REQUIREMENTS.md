## In Scope (All Delivered)

### Navigation (Tab Consolidation)

- [x] **NAV-01**: User can navigate the app via three top-level section tabs: Analyse, Plan, and Squad — Phase 36
- [x] **NAV-02**: Analyse section groups the following sub-tabs: Gem Ratings, Insights, DefCon Analysis, Set Pieces — Phase 36
- [x] **NAV-03**: Plan section groups the following sub-tabs: Planner, Club Form, Value Gems — Phase 36
- [x] **NAV-04**: Squad section shows Squad & Transfers as a single view (no sub-tabs) — Phase 36
- [x] **NAV-05**: Mobile nav reflects the 3-section grouping with accessible sub-tab navigation within each section — Phase 36

### GemTable View Presets

- [x] **GEM-01**: User can switch the GemTable between three named view presets: Default, Compact, and Analysis — Phase 37
- [x] **GEM-02**: Compact preset shows a reduced column set: Player, Pos, Gem score, xPts 1GW, Risk badge only — Phase 37
- [x] **GEM-03**: Analysis preset shows additional xG/xA detail columns alongside the standard set — Phase 37
- [x] **GEM-04**: Selected preset persists across tab switches within a session (no reset on tab change) — Phase 37

### Player Comparison

- [x] **CMP-01**: User can open a player comparison modal from any GemTable row via a compare icon on that row — Phase 39
- [x] **CMP-02**: Comparison modal lets user pick a second player to compare against (search from full player list) — Phase 39
- [x] **CMP-03**: Comparison modal shows xPts projection (1GW / 3GW / 5GW + 90th-percentile ceiling) side by side for both players — Phase 39
- [x] **CMP-04**: Comparison modal shows Gem score breakdown (all 7 component scores) for each player side by side — Phase 39
- [x] **CMP-05**: Comparison modal shows next 5 fixtures with colour-coded difficulty for each player — Phase 39
- [x] **CMP-06**: Comparison modal shows BUY/SELL regression signal, DIFF/TRAP flag, and rotation risk badge for each player — Phase 39

### Data Freshness

- [x] **FRE-01**: App always shows how long ago the data was last updated (e.g. "Updated 3h ago") on every tab — Phase 38
- [x] **FRE-02**: Data age indicator is visible on every tab without the user needing to navigate to a specific location — Phase 38
- [x] **FRE-03**: Data age is displayed as human-readable relative time, not an ISO timestamp — Phase 38

### Projection Accuracy & Backtesting

- [x] **ACC-01**: Pipeline computes per-GW actual vs predicted delta for both proj_pts_1gw and xPts_1gw over last 5 completed gameweeks — Phase 40
- [x] **ACC-02**: User can view a GW-by-GW accuracy table showing top predicted haulters vs who actually scored 10+ pts, with hit rate % per GW — Phase 41
- [x] **ACC-03**: User can view a "correctly flagged haulters" list — Phase 41
- [x] **ACC-04**: User can view a player-level comparison table showing prediction error (delta), sortable by biggest miss — Phase 41
- [x] **ACC-05**: GemTable shows a last-GW actual points column alongside the xPts_1gw column — Phase 41
- [x] **ACC-06**: Projection model with demonstrably lower accuracy (proj_pts, 9.0% vs xPts 16.7%) removed — Phase 41
