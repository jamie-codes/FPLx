## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge horizontal padding (`px-2`) |
| sm | 8px | Compact element spacing, stat gap in summary card |
| md | 16px | Default element spacing, card inner padding |
| lg | 24px | Section padding, space between cards |
| xl | 32px | Layout gaps between major blocks |
| 2xl | 48px | Major section breaks (e.g. chart top margin) |
| 3xl | 64px | Page-level spacing (not used in this phase) |

Exceptions:
- Touch targets: `min-h-[44px]` on sub-tab buttons (mobile); `sm:min-h-0` releases constraint on desktop.
- Chart container height: 288px (fixed — inherited from AccuracyTab calibration chart pattern).
- Badge vertical padding: `py-0.5` (2px — matches existing HitRateBadge pattern exactly).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (normal) | 1.5 |
| Label / badge | 12px (text-xs) | 400 (normal) | 1.4 |

- Stat values in REV-01 summary card use `text-base font-semibold text-zinc-900 dark:text-zinc-100`.
- Grade letter in REV-02 uses `text-lg font-semibold` matching section heading weight.

### SeasonReviewTab (root component)

### REV-01 Summary Card

Layout: `<div className="rounded border border-zinc-200 dark:border-zinc-700 bg-white dark:bg-zinc-800 p-4">`

Stat grid: `<dl className="grid grid-cols-2 sm:grid-cols-3 gap-4">`

Each stat cell:
```
<div>
  <dt className="text-xs text-zinc-500 dark:text-zinc-400">{label}</dt>
  <dd className="text-base font-semibold text-zinc-900 dark:text-zinc-100 tabular-nums">{value}</dd>
</div>
```

Stats declared (6 cells, order: left-to-right, top-to-bottom):
1. Total Rank — overall rank at end of available GWs (formatted with locale separator e.g. `1,234,567`)
2. Total Points — cumulative points (integer)
3. Captain Hit Rate — captain EV rate as percentage (e.g. `62.5%`)
4. Transfer Net — net gain/loss in points from transfers (signed, e.g. `+8` or `−4`); colored per semantic above
5. Best GW — highest single-GW score (integer, with "GW{N}: {pts}pts" label pattern e.g. `GW7: 94pts`)
6. Worst GW — lowest single-GW score (integer, same pattern)

N/A rendering: `<span className="text-zinc-400 dark:text-zinc-500">N/A</span>` for GWs before app deployment.

<h2 className="text-lg font-semibold mb-3">Decision Quality</h2>

Grade awaiting data: render `<span className="text-zinc-400 dark:text-zinc-500">—</span>` in badge position while hooks are loading.

- User score Line: `dataKey="points"`, `stroke="currentColor"`, `strokeWidth={2}`, `dot={<ChipDot />}`, `activeDot={{ r: 5 }}`, `isAnimationActive={false}`
- Avg manager Line: `dataKey="avgManagerScore"`, `stroke="rgba(161,161,170,0.7)"`, `strokeWidth={1}`, `strokeDasharray="4 4"`, `dot={false}`, `isAnimationActive={false}`
- Tooltip: custom `<SeasonChartTooltip />` component

**ChipDot component** (renders chip marker on user score line):
```tsx
function ChipDot(props: any) {
  const { cx, cy, payload } = props
  if (!payload?.chipPlayed) return <circle cx={cx} cy={cy} r={3} fill="currentColor" stroke="none" />
  return <circle cx={cx} cy={cy} r={6} fill="#f59e0b" stroke="none" />
}
```

**SeasonChartTooltip content:**
```
<div className="rounded border border-zinc-200 dark:border-zinc-700 bg-white dark:bg-zinc-900 px-3 py-2 text-xs shadow-sm">
  <p className="font-semibold text-zinc-900 dark:text-zinc-100 mb-1">GW{gw}</p>
  <p className="text-zinc-700 dark:text-zinc-300">Your score: {points}pts</p>
  <p className="text-zinc-700 dark:text-zinc-300">Avg manager: {avgManagerScore}pts</p>
  <p className="text-zinc-700 dark:text-zinc-300">Overall rank: {overallRank formatted with locale separator}</p>
  {chipPlayed && <p className="text-amber-600 dark:text-amber-400 mt-1">Chip: {chipName}</p>}
</div>
```

Chip name display in tooltip: map chip slugs to display names matching BackTab pattern:
- `bboost` → "Bench Boost"
- `3xc` → "Triple Captain"
- `freehit` → "Free Hit"
- `wildcard` → "Wildcard"

## Interaction Contracts

### Sub-tab button
- Role: `button` with `aria-pressed={active}` (matches AccuracyTab pattern)
- `role="group"` on container with `aria-label="Analyse section"` (or inherit page-level group)
- Keyboard: tab-navigable, `active:scale-95` press feedback
- Min touch target: `min-h-[44px]` on mobile, `sm:min-h-0` on desktop

### Empty state
- Rendered when `!teamId` (null or empty string)
- Card with border, no interactive elements — purely informational
- Same visual chrome as other cards (border, bg-white dark:bg-zinc-800)

### Grade loading
- While `useSeasonReview` or `useSeasonAnalytics` are loading, render `—` in grade badge position
- Grade computed client-side only after both hooks resolve

### Chart tooltip
- Custom tooltip component (not recharts default)
- Shows on hover of any data point
- Rank shown in tooltip only (no second y-axis — D-01 locked)
- Chip name shown conditionally only when `chipPlayed` is non-null

### Accessibility
- `<section aria-label="Season review">` wraps all content
- Chart container: `data-testid="season-points-chart"` for test targeting
- All `<dl>/<dt>/<dd>` for stats (semantic definition list — not a table)
- Grade badge: `aria-label="Decision quality grade: {grade}"` on the span
