## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internal horizontal pad (`px-2`) |
| sm | 8px | Gap between filter pills, gap between article card elements |
| md | 16px | Card inner padding, section default spacing |
| lg | 24px | Space between feed section and filter row |
| xl | 32px | Layout gaps between major blocks |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (not used in this phase) |

Exceptions:

- Touch targets: `min-h-[44px]` on filter pill buttons (mobile); `sm:min-h-0` releases constraint on desktop. Matches AccuracyTab position-filter pill pattern exactly.

Note on source badge micro-padding: The article card source badge (`px-2 py-0.5`) uses `py-0.5` (2px) — this value is inherited unchanged from the existing `StatusLabelBadge` and `MinsRiskBadge` shared component patterns. It is a component-internal micro-padding from the established badge shape contract, not a layout spacing value, and is therefore outside the layout spacing contract scope. It is not a new spacing declaration for this phase.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / article title | 14px (text-sm) | 400 (normal) | 1.5 |
| Label / badge | 12px (text-xs) | 400 (normal) | 1.4 |
| Section heading | 18px (text-lg) | 600 (semibold) | 1.2 |
| Source badge text | 12px (text-xs) | 600 (semibold) | 1.4 |

Notes:
- Article title link: `text-sm font-normal` — no bold emphasis; the link underline provides the interactive affordance.
- Source badge `[SKY]` / `[BBC]`: `text-xs font-semibold` — weight distinguishes it from the date label.
- Relative date ("3h ago"): `text-xs text-zinc-500 dark:text-zinc-400` — subdued, non-interactive.
- Stale banner copy: `text-sm` — body-level prominence (warning should read at a glance).
- Filter pill labels: `text-xs font-semibold uppercase tracking-wide` — matches AccuracyTab POSITION_PILLS exactly.

### Filter pill row

```tsx

  aria-label="Filter transfer news by type"

      ? 'bg-zinc-900 text-white dark:bg-zinc-100 dark:text-zinc-900'
      : 'bg-zinc-100 text-zinc-700 dark:bg-zinc-800 dark:text-zinc-300 hover:bg-zinc-200 dark:hover:bg-zinc-700'

        type="button"
        role="tab"

        onClick={() => setActiveFilter(pill.value)}
        className={`min-h-[44px] sm:min-h-0 px-3 py-1 rounded text-xs font-semibold uppercase tracking-wide transition-colors ${cls}`}
      >
        {pill.label}

  })}
```

## Interaction Contracts

### Filter pills
- Role: `button` with `role="tab"` and `aria-selected={active}`.
- Container: `role="group"` with `aria-label="Filter transfer news by type"`.
- Single-select (radio style) — one active at a time (D-06).
- Default: `'all'` on tab mount (D-07).
- Keyboard: tab-navigable; `transition-colors` for visual feedback.
- Min touch target: `min-h-[44px]` on mobile, `sm:min-h-0` on desktop.

### Article title link
- `<a target="_blank" rel="noopener noreferrer">` — opens article in new tab (D-02).
- Hover: underline decoration.
- No JavaScript — pure anchor tag.

### Stale feed banner
- Non-interactive — purely informational.
- Displayed above filter pills when `scraped_at` is older than 24h (D-04).
- Articles still display below the banner.

### Confirmed Signing badge tooltip
- `title` attribute only — native browser tooltip (D-15).
- No custom tooltip component needed.

### GemTable expanded row
- Badge renders conditionally — only when `useTransferNews` data contains a `confirmed_signing` article matching `player.id` (D-12).
- If multiple matching articles: use most recent by `published ?? scraped_at` (D-12).
- Badge absent when no match — no placeholder element rendered (D-13).

### Accessibility
- `<section aria-label="Summer window transfer news">` wraps tab content.
- `<article>` semantic element for each news card.
- Source badge text is self-describing (`[SKY]` / `[BBC]`) — supplementary `aria-label` not required.
- Filter pill container uses `role="group"` rather than `role="tablist"` — pills filter content in same view (not switching panels), so group + aria-selected is correct semantics.
- Stale banner: `⚠` icon is `aria-hidden="true"`; banner text carries full meaning without it.
