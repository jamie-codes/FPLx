<objective>
Fix four Python backend tech debt items flagged by the v1.4 audit:

- WR-02: Exclude BGW players (xPts_1gw=0 or None, meaning no fixture) from the TRAP position-median so blank-gameweek weeks don't skew the median down and trigger false TRAP flags for the rest of the squad.
- WR-03: Change the TRAP gate predicate from `not above_median` (which catches ≤ median) to strict `xpts_1gw < position_median` so exactly-median players are not flagged as template traps.
- WR-05: Add `sample_n > 0` guards in `_player_patterns` (insights.py) so zero-count statements ("0 of N regular starters carry a BUY signal") are never emitted — these are trivially true and excluded by INS-04.
- WR-06: Fix `upload.py` type annotation `data: dict` → `data: list | dict` so the insights payload (a list) doesn't violate the declared type.

All four are independent one-file changes. No new tests are required by the phase (these are correctness fixes to pipeline logic) but existing Python tests must remain green.
</objective>
