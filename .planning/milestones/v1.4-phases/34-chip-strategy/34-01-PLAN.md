Implementation notes (apply during coding):

1. **Polarity (Pitfall 1):** `ease = 1 - attacking_difficulty` everywhere. Never return raw `attacking_difficulty`.

2. **BGW (Pitfall 2):** When `fixtures.find(f => f.event_id === gw)` returns undefined, use `BGW_NEUTRAL_EASE = 0.5` and mark `isBGW: true` on the GWEaseScore for the BB/TC aggregate; for FH greedy weighting set the player's weighted contribution to `xPts_1gw * BGW_NEUTRAL_EASE` (do NOT set to 0 — they may still be the best available pick for that slot).

3. **TC fallback chain (Pitfall 3):** ranking key = `player.xPts_90th_1gw ?? player.xPts_1gw ?? player.proj_pts_1gw ?? 0`. Document the chain in JSDoc.

4. **FH formation greedy (RESEARCH §Pattern 4):** sort all eligible players (status === 'a') by weighted DESC. Iterate; for each candidate, check (a) still need this position-type slot, (b) team count < FH_TEAM_CAP, (c) running cost + now_cost <= budget. Stop when all 15 slots filled. Slot quotas to fill are: GK=2, DEF starts at 3 (room to grow to 5), MID starts at 2 (grow to 5), FWD starts at 1 (grow to 3). After hitting minimums (2+3+2+1 = 8) and adding 4 bench/flex slots filling whichever position has the next-highest weighted candidate within max bounds, you reach 15. Implement the simplest correct greedy that satisfies all constraints — 15 iterations max.

5. **FH team cap (Pitfall 4):** `const teamCount = new Map<number, number>()` incremented per pick; skip player when `(teamCount.get(player.team) ?? 0) >= FH_TEAM_CAP`.

6. **FH budget (Pitfall 5):** `const budget = bankBalance + (currentSquadIds?.reduce((sum, id) => sum + (sellPrices?.[id] ?? playerMap.get(id)?.now_cost ?? 0), 0) ?? FH_DEFAULT_BUDGET_TENTHS)`.

7. **FH top-11 score:** after building the 15-player squad, the score for that GW = (best GK by weighted) + sum(top-10 outfield by weighted).

8. **Tie-break for bestGw:** earliest GW wins (use `>` not `>=` when scanning).

9. **Defensive zero-data return:** if `players.length === 0` or `clubFormMap.size === 0`, return 5 entries with ease=0 / isBGW=true and an empty suggestedSquad. Never throw.

```typescript
import { useQuery } from '@tanstack/react-query'

export interface ChipHistoryEntry {
  name: string      // 'bboost' | '3xc' | 'freehit' | 'wildcard'
  time: string      // ISO timestamp
  event: number     // gameweek number when the chip was played
}

interface ChipHistoryResponse {
  chips?: ChipHistoryEntry[]
  // FPL also returns `current` and `past` arrays — we ignore them.
}

async function fetchChipHistory(teamId: string): Promise<ChipHistoryEntry[]> {
  const res = await fetch(`/api/fpl/entry/${teamId}/history/`)
  if (!res.ok) {
    throw new Error(`Chip history fetch failed: ${res.status}`)
  }
  const data: ChipHistoryResponse = await res.json()
  return data.chips ?? []
}

/**
 * Fetch the manager's used-chips history via the existing FPL proxy.
 *
 * Security: T-34-01 mitigation — `teamId` MUST be numeric. The `/^\d+$/.test`
 * guard prevents URL injection through the `[...proxy]` path segment.
 *
 * @param teamId  string from localStorage; null disables the query
 */
export function useChipHistory(teamId: string | null) {
  return useQuery<ChipHistoryEntry[]>({
    queryKey: ['chip-history', teamId],
    queryFn: () => fetchChipHistory(teamId!),
    enabled: !!teamId && /^\d+$/.test(teamId),
    staleTime: 1000 * 60 * 60 * 6, // 6 hours — chip usage rarely changes mid-season
    retry: 1,
  })
}
```
