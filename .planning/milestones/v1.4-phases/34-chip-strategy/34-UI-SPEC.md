## Color

| Role | Tailwind token | Usage |
|------|---------------|-------|
| Dominant (60%) | `bg-white dark:bg-zinc-900` | Panel card background; FH expanded area background is `bg-zinc-50 dark:bg-zinc-800` |
| Secondary (30%) | `border-zinc-200 dark:border-zinc-700` | Panel card border; table dividers `border-zinc-100 dark:border-zinc-800` |
| Accent — BEST cell (10%) | `bg-green-500` + `ring-2 ring-green-700 dark:ring-green-300` | Highlighted best-GW ease cell only |
| Non-best ease cells (green scale) | See Ease Cell Green Scale below | Ease cells that are not the best GW |
| Used-chip greyed state | `opacity-40` applied to chip row container | Entire row dimmed; no colour accent |
| Chip name badge — unused | `bg-zinc-100 dark:bg-zinc-800 text-zinc-700 dark:text-zinc-300` | Chip label pill for BB, TC, FH (unused state) |
| Chip name badge — used | `bg-zinc-200 dark:bg-zinc-700 text-zinc-400 dark:text-zinc-500` | Used chip label pill |
| "Used GWN" label | `text-xs text-zinc-400 dark:text-zinc-500` | Replaces recommendation label for used chips |
| Expand chevron | `text-zinc-400 dark:text-zinc-500` | ▴ / ▾ FH expand affordance |
| FH expanded table header | `text-zinc-500 dark:text-zinc-400` | Column headers |
| FH expanded table border | `border-b border-zinc-100 dark:border-zinc-800` | Header/body divider |
| Loading / meta text | `text-sm text-zinc-500 dark:text-zinc-400` | Loading and subheading copy |
| Error text | `text-sm text-red-600 dark:text-red-400` | Error message |

**Ease Cell Green Scale (5-cell bar):**

Each cell maps the GW's ease score (0.0 hardest → 1.0 easiest) to a fill class:

| ease range | Cell fill class | Meaning |
|------------|-----------------|---------|
| >= 0.75 | `bg-green-500` | Very easy fixture |
| 0.55 – 0.74 | `bg-green-300 dark:bg-green-700` | Easy fixture |
| 0.40 – 0.54 | `bg-amber-300 dark:bg-amber-600` | Neutral fixture |
| 0.25 – 0.39 | `bg-red-300 dark:bg-red-700` | Difficult fixture |
| < 0.25 | `bg-red-500` | Very difficult fixture |

The best-GW cell (the cell with the highest ease score across the 5) additionally receives: `ring-2 ring-offset-1 ring-green-700 dark:ring-green-300`

Unused cells (for BGW — blank gameweek) receive: `bg-zinc-200 dark:bg-zinc-700`

**Accent reserved for:**
- Best-GW ease cell ring highlight ONLY
- No other elements in this phase use an accent ring or saturated colour

Source: EaseBar.tsx (TIER_BG palette), FixtureBadges.tsx (TIER_COLOURS), InsightsTab.tsx (badge classes), FixtureEaseRankingPanel.tsx (expanded bg, border, text classes)

### EaseCellBar (5-cell grid)

```
<div
  className="flex gap-1"
  role="img"
  aria-label="Ease across next 5 GWs: GW{a} easy, GW{b} neutral, ..."
>
  {cells.map((cell) => (
    <div
      key={cell.gw}
      title={`GW${cell.gw}: ease ${(cell.ease * 100).toFixed(0)}%`}
      className={`w-6 h-3 rounded-sm {fillClass} {ringClass if isBest}`}
      data-testid={`ease-cell-${cell.gw}`}
      data-best={cell.isBest}
    />
  ))}
</div>
```

Cell dimensions: `w-6 h-3` (24px × 12px). Gap between cells: `gap-1` (4px).
Total bar width: 5 × 24px + 4 × 4px = 136px.
BGW (blank GW) cell: `bg-zinc-200 dark:bg-zinc-700` — no ease score available.

## States and Interactions

### Loading state

```
<p className="text-sm text-zinc-500 dark:text-zinc-400 text-center py-8">
  Loading chip strategy…
</p>
```

Source: CaptainPicksPanel.tsx loading pattern

### Error state

```
<p className="text-sm text-red-600 dark:text-red-400 py-4">
  Failed to load chip strategy. Check squad data and refresh.
</p>
```

### No team ID state

```
<p className="text-sm text-zinc-500 dark:text-zinc-400 py-4">
  Enter your FPL Team ID to see chip recommendations.
</p>
```

Shown when `teamId` is null in localStorage — chip history and bench data both require a team ID.

### All chips used state

All 3 rows render in greyed-out state. Panel heading and subheading remain at full opacity. Panel is still visible (informational — user sees when each chip was played).

### Used chip row

- `opacity-40` on the `<li>` container
- `aria-disabled="true"` on the `<li>`
- RecommendationLabel shows "Used GW{N}" in `text-xs text-zinc-400 dark:text-zinc-500`
- EaseCellBar is still rendered (provides historical context) but cells are all `bg-zinc-200 dark:bg-zinc-700` (muted — no intensity scale)
- No click handler

### FH expansion keyboard

- `onKeyDown`: Enter key and Space key both toggle expansion (preventDefault on Space to avoid page scroll)
- Focus ring: browser default (`outline`) — not overridden (matches FixtureEaseRankingPanel pattern)

## Data Flow Summary

| Chip | Data source | Score type |
|------|-------------|-----------|
| Bench Boost | `useSquad(teamId)` positions 12–15, `useClubForm()` `upcoming_fixtures[].attacking_difficulty` | Sum bench players' team ease per GW |
| Triple Captain | `usePlayers()` `xPts_90th_1gw` (top-3 candidates), `useClubForm()` `upcoming_fixtures[].attacking_difficulty` | Best candidate's fixture ease per GW |
| Free Hit | `usePlayers()` `xPts_1gw`, `useClubForm()` per-GW fixture ease | Greedy squad xPts × fixture ease weight |
| Chip eligibility | FPL proxy `/api/fpl/entry/{id}/history/` `chips[]` | `name` + `event` fields |

All scoring is client-side via `useMemo` in the component — no new API route or hook needed for chip scores.
