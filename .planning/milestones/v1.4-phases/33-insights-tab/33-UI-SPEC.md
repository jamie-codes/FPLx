## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (card statement text) | 14px (`text-sm`) | 400 (normal) | 1.5 |
| Label (badge text, metadata) | 12px (`text-xs`) | 400 (normal) | 1.5 |
| Card heading / section subtitle | 14px (`text-sm`) | 600 (`font-semibold`) | 1.5 |
| Section heading (category title) | 18px (`text-lg`) | 600 (`font-semibold`) | 1.2 |

Rules:
- Section headings use `text-lg font-semibold mb-2` — matching `DefConTables.tsx` (`<h2 className="text-lg font-semibold mb-2">`).
- Card statement text uses `text-sm` (14px) at weight 400 — the primary readable content.
- Badge and metadata text uses `text-xs` (12px) at weight 400 — de-emphasised data labels.
- No `text-xl` or `font-bold` in this phase; section headings match the `CaptainPicksPanel` / `DefConTables` lg+semibold convention.

Source: `src/components/captaincy/CaptainPicksPanel.tsx` line 78 (`text-lg font-semibold`), `src/components/defcon/DefConTables.tsx` lines 124 and 133 (`text-lg font-semibold mb-2`).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` light / `#0a0a0a` dark | Page background (`--background`) |
| Secondary (30%) | `bg-white dark:bg-zinc-900` + `border-zinc-200 dark:border-zinc-700` | Insight cards (bordered card surface) |
| Accent HIGH (green, ~5%) | `bg-green-100 text-green-800 dark:bg-green-900 dark:text-green-200` | HIGH confidence tier badge only |
| Accent MEDIUM (amber, ~3%) | `bg-amber-100 text-amber-800 dark:bg-amber-900 dark:text-amber-200` | MEDIUM confidence tier badge only |
| Accent LOW (zinc, ~2%) | `bg-zinc-100 text-zinc-600 dark:bg-zinc-800 dark:text-zinc-400` | LOW confidence tier badge only |
| Muted text | `text-zinc-500 dark:text-zinc-400` | Metadata lines, empty state body, loading states |
| Destructive | `text-red-600 dark:text-red-400` | Error state message only |

Accent reserved for:
1. HIGH badge — confidence_pct >= 70%
2. MEDIUM badge — confidence_pct 50–69%
3. LOW badge — confidence_pct < 50% (and sample_total >= 10)

No accent on headings, card borders, or body text.

Source: `33-CONTEXT.md` D-05 (badge colour tokens, locked decision). Verified against `src/components/gem-table/RegressionSignalBadge.tsx` (green/amber pill pattern) and `src/components/captaincy/CaptainPicksPanel.tsx` (card surface and error copy tokens).

## Component Inventory

### InsightCard (new, inline in InsightsTab.tsx)

Visual structure:

```
┌─────────────────────────────────────────────────────┐
│  [statement text — text-sm weight-400]               │
│  [TIER BADGE]  ← text-xs rounded px-2 py-1           │
└─────────────────────────────────────────────────────┘
```

- Container: `rounded border border-zinc-200 dark:border-zinc-700 bg-white dark:bg-zinc-900 p-4 space-y-2`
- Statement: `<p className="text-sm">` — plain body text, no bold
- Badge: `<span className="inline-block text-xs font-normal rounded px-2 py-1 cursor-help {TIER_CLASSES[tier]}" title="...">`
- Tooltip (HTML `title` attribute): `"True in {confidence_pct}% of fixtures — {sample_n}/{sample_total} matches"`

### InsightsTab (new)

Structure:
```
<section className="mt-6 space-y-6">

  <div className="space-y-3">
    <InsightCard /> × N

  <h2 className="text-lg font-semibold mb-2">Attacking Patterns</h2>
  ...
  <h2 className="text-lg font-semibold mb-2">Player-Specific Patterns</h2>
  ...
  <h2 className="text-lg font-semibold mb-2">Captaincy Patterns</h2>
  ...
  <p className="text-xs text-zinc-500 dark:text-zinc-400 mt-4">

  </p>
```

- All four category sections always rendered (no accordion, no collapse) — D-08 locked
- No pagination, no filter UI — D-10 locked
- Footnote `text-xs text-zinc-500` below all cards explaining the minimum sample floor

### Confidence Tier Badge

```typescript
const TIER_CLASSES = {
  HIGH:   'bg-green-100 text-green-800 dark:bg-green-900 dark:text-green-200',
  MEDIUM: 'bg-amber-100 text-amber-800 dark:bg-amber-900 dark:text-amber-200',
  LOW:    'bg-zinc-100 text-zinc-600 dark:bg-zinc-800 dark:text-zinc-400',
} as const

function getTier(pct: number): keyof typeof TIER_CLASSES {
  if (pct >= 70) return 'HIGH'
  if (pct >= 50) return 'MEDIUM'
  return 'LOW'
}
```

Source: `33-CONTEXT.md` D-04 and D-05 (locked). Tooltip mechanism: HTML `title` attribute — consistent with `CaptainPicksPanel.tsx` line 25 and `RegressionSignalBadge.tsx`.

## Interaction States

| State | Trigger | Visual |
|-------|---------|--------|
| Loading | `isLoading === true` from `useInsights()` | Single `<p className="text-sm text-zinc-500 dark:text-zinc-400 text-center py-8">Loading insights…</p>` — no skeleton |
| Error | `error` truthy from `useInsights()` | `<p className="text-sm text-red-600 dark:text-red-400 py-4">Failed to load insights. Check the pipeline output and refresh.</p>` |
| Empty (seeded `[]`) | `data` is empty array | Section headings hidden; single `<p>No insights available yet</p>` + body copy |
| Populated | `data.length > 0` | Full four-section layout, all categories with their cards |
| Badge hover | User hovers badge element | Browser native tooltip via `title` attribute — no custom tooltip library |
| Tab active | `activeTab === 'insights'` | `border-b-2 border-zinc-900 dark:border-white text-zinc-900 dark:text-white` — same active state as all other tabs |
| Tab inactive | `activeTab !== 'insights'` | `text-zinc-500 dark:text-zinc-400 hover:text-zinc-700 dark:hover:text-zinc-200` |

Source: `CaptainPicksPanel.tsx` for loading/error state shape. `src/app/page.tsx` lines 37–39 for active/inactive tab class pattern.
