## Typography

The phase extends `FixtureEaseRankingPanel` which uses `text-sm` body. The inline player table uses `text-xs` for data density. Four sizes total, two weights — within the design-quality budget.

| Role | Tailwind class | Computed | Weight | Line height | Usage |
|------|----------------|----------|--------|-------------|-------|
| Section heading (existing) | `text-xl font-bold` | 20px | 700 | 1.75 | "Fixture Ease Ranking" — unchanged, inherited from existing panel |
| Team row rank + name | `text-sm` | 14px | 400 | 1.5 | Existing row text — unchanged |
| TARGET badge label | `text-xs font-normal` | 12px | 400 | 1.33 | "TARGET" pill appended after team name |
| Player table header labels | `text-xs font-normal text-zinc-500 dark:text-zinc-400` | 12px | 400 | 1.33 | "Name", "Pos", "xGI%", "xPts", "Signal", "Diff" column headers |
| Player name in table | `text-xs font-semibold` | 12px | 600 | 1.33 | Player name — the only semibold element in the table |
| Player data cells | `text-xs` | 12px | 400 | 1.33 | Pos, xGI%, xPts_1gw value; Signal and Diff cells render existing badge components |

## Color

Project uses Tailwind's `zinc-*` neutral scale for chrome and named hue scales for semantic state. The 60/30/10 split maps onto the existing palette.

| Role | Light token | Dark token | Tailwind class | Usage |
|------|-------------|-----------|----------------|-------|
| Dominant (60%) — page background | `white` | `#0a0a0a` | inherited from page | Surface beneath the panel |
| Secondary (30%) — expanded player block | `zinc-50` | `zinc-800` | `bg-zinc-50 dark:bg-zinc-800` | Subtle background for the expanded player list block; distinguishes it from the team row without adding card borders |
| Secondary border | `zinc-100` | `zinc-800` | `border-b border-zinc-100 dark:border-zinc-800` | Player table header separator |
| Muted text | `zinc-500` | `zinc-400` | `text-zinc-500 dark:text-zinc-400` | Column headers, rank numbers, ease percentages |
| Body text | (default) | (default) | inherit | Team names, player names |
| Accent — TARGET badge | `green-100` / `green-800` | `green-900` / `green-200` | `bg-green-100 text-green-800 dark:bg-green-900 dark:text-green-200` | TARGET badge ONLY — reserved exclusively for this element |
| Chevron (toggle) | `zinc-400` | `zinc-500` | `text-zinc-400 dark:text-zinc-500` | Expand/collapse chevron icon |
| Destructive | `red-500` | (inherited) | `text-red-500` | Error state copy ONLY (inherited from existing panel) |

**Accent reserved for:** the TARGET badge on team rows only. No other element in this phase uses a green hue accent. The green hue is semantically consistent with `RegressionSignalBadge`'s BUY signal and `DifferentialBadge`'s DIFF badge — all three use the same green scale to signal a positive/opportunity state. This alignment is intentional.

**xGI% value coloring:** none. The xGI% value renders as plain body text (`text-xs`). No colour-coding of the percentage — data density would make colour-coding noisy, and the ranking already conveys relative magnitude.

**Row hover:** none. Team rows in the existing panel have no hover state — the extension MUST NOT add `hover:bg-*` to avoid visual inconsistency with non-expandable rows.

**Forbidden:**
- No `bg-violet-*`, `bg-blue-*`, `bg-amber-*` on team rows or the expanded player block.
- No gradient backgrounds, no box shadows (`shadow-*`).
- No row background change when the TARGET badge is present (D-04 from CONTEXT: badge only, no row colour change).
- No emoji glyphs.

## Copywriting Contract

All strings are locked. Executor MUST use these verbatim — including punctuation, capitalisation, and dash style.

### TARGET badge

| Element | Copy |
|---------|------|
| Badge label | `TARGET` (all caps, no icon) |
| Badge `title` tooltip | `4+ favourable fixtures in the next 5 GWs (attacking difficulty < 0.5). Click to see top players.` |

### Chevron toggle `title` attribute

| State | `title` string |
|-------|----------------|
| Row collapsed (showing expand chevron) | `Show top players for this team` |
| Row expanded (showing collapse chevron) | `Hide player list` |

### Expanded player table column headers

| Column | Header label |
|--------|-------------|
| Player name | `Player` |
| Position | `Pos` |
| xGI involvement % | `xGI%` |
| Expected points (next GW) | `xPts` |
| Regression signal | `Signal` |
| Differential flag | `Diff` |

### xGI% display format

| Condition | Display |
|-----------|---------|
| `teamTotal > 0` | `{(pct * 100).toFixed(0)}%` (e.g. "34%") |
| `teamTotal === 0` | `—` (em-dash, `text-zinc-400`) |

### xPts display format

`{player.xPts_1gw.toFixed(1)}` (e.g. "6.3") — no suffix, no label. Column header provides context.

### Signal column

Renders `<RegressionSignalBadge signal={player.regression_signal} delta={player.actual_vs_xg_delta} />` directly. Badge component owns its own copy (BUY / SELL / em-dash). Do not duplicate badge copy here.

### Diff column

Renders `<DifferentialBadge flag={player.differential_flag} ownership={player.selected_by_percent} />` directly. Badge component owns its own copy (DIFF / TRAP / em-dash). Do not duplicate badge copy here.

### State copy

| State | Element | Copy |
|-------|---------|------|
| Loading | `<p className="text-gray-500 dark:text-zinc-400">` | `Loading fixture ease...` (inherits exact string from existing `FixtureEaseRankingPanel.tsx:29`) |
| Error | `<p className="text-red-500">` | `Failed to load fixture ease: {error message}` (inherits exact string from existing panel) |
| No TARGET teams (all teams have < 4 favourable fixtures) | no additional UI — TARGET badge simply absent on all rows; panel renders normally | n/a |
| Expanded list — no eligible players (team has no `status === 'a'` players with xGI data) | `<p className="text-xs text-zinc-500 dark:text-zinc-400 py-1">` | `No available players with xGI data for this team.` |

### Destructive actions

None. The panel is read-only. No buttons that mutate state, no forms, no confirmation dialogs.

### Primary CTA

None. The expand interaction is a disclosure toggle, not a CTA. No button labels required beyond the implicit chevron affordance.

## Interaction Contract

| Interaction | Behaviour | Source pattern |
|-------------|-----------|----------------|
| Click on TARGET-badged team row | Toggles expanded player list inline below the row. Only one team can be expanded at a time — clicking a second TARGET row collapses the first and expands the second. | `useState<number \| null>` for `expandedTeamId` in panel |
| Click on non-TARGET team row | No effect — rows without TARGET badge are not expandable. No visual feedback on click. | CONTEXT D-05 |
| Chevron icon | Renders right-aligned on TARGET rows. Points down (`▾` or equivalent) when collapsed, up (`▴`) when expanded. Unicode glyphs or Tailwind-compatible SVG both acceptable — executor chooses. | Project pattern: Unicode glyphs preferred (VarianceBadge.tsx) |
| Hover on TARGET badge | Native `title` tooltip (see Copywriting Contract). | `RegressionSignalBadge.tsx:22` pattern |
| Hover on chevron | Native `title` tooltip (see Copywriting Contract). | same |
| Hover on Signal badge in player table | Delegates to `RegressionSignalBadge` own `title` attribute — no additional handling needed. | `RegressionSignalBadge.tsx:22` |
| Hover on Diff badge in player table | Delegates to `DifferentialBadge` own `title` attribute. | `DifferentialBadge.tsx:24` |
| Tab focus | TARGET row `<li>` receives focus naturally if made interactive (add `tabIndex={0}` + `onKeyDown` Enter/Space handler). Accessibility minimum: keyboard-operable expand/collapse for TARGET rows. | Upgrade from Phase 31 convention — Phase 31 acknowledged gap; this phase MUST close it for the expand interaction |
| Mobile portrait | Expanded player table scrolls horizontally if it overflows. Signal and Diff columns are NOT hidden on mobile (data is actionable). Wrap the table in `overflow-x-auto`. | CONTEXT (Claude's Discretion: recommend horizontal scroll) |
| GW toggle change (1/3/5 GW) | Changes fixture ease ranking order. If the currently expanded team drops below the TARGET threshold under the new window, it collapses automatically (re-evaluate TARGET status on each render — the count is derived from `upcoming_fixtures`, not the aggregate ease key). | CONTEXT D-02: green-run check always uses 5 GW window, independent of toggle. Executor note: TARGET badge visibility is always 5-GW-based; only the rank order changes with the toggle. No automatic collapse needed — a team TARGET-qualified in 5-GW view remains qualified regardless of 1/3-GW ease rank. |
| ATT/DEF toggle change | Changes ease ranking order only. TARGET qualification is always based on `attacking_difficulty` (CONTEXT D-01, D-03) — ATT/DEF toggle does NOT affect TARGET badge display. | CONTEXT D-02 |
| Loading → loaded transition | Replace loading paragraph with panel content. No skeleton, no animation. | FixtureEaseRankingPanel.tsx:28-37 |

**Expanded block placement:** The expanded block is rendered as a sibling element immediately after the `<li>` for the expanded team — NOT inside the `<li>`. The outer `<ul>` is a flat list; the expansion uses a fragment or an adjacent `<div>` keyed to the team.

**Alternative implementation note:** If the executor uses a React fragment wrapping `<li>` + expansion `<div>` inside the `<ul>`, the markup is semantically acceptable since the `<div>` is not a list child. Executor may also use a `<li>` wrapper with `display: contents` or move to a `<div>`-based list if `<ul>/<li>` semantics create layout issues.

**Player table column widths:**

| Column | Min width | Notes |
|--------|-----------|-------|
| Player | `w-28` or `min-w-28` | Truncate with `truncate` if name overflows |
| Pos | `w-8` | 3-char max (GK, DEF, MID, FWD) |
| xGI% | `w-10 text-right` | Right-aligned number |
| xPts | `w-10 text-right` | Right-aligned number |
| Signal | `w-14` | Hosts badge component |
| Diff | `w-14` | Hosts badge component |

**Responsive behaviour:**

| Breakpoint | Team row | Expanded table |
|------------|----------|---------------|
| Mobile portrait (< 640px) | TARGET badge and chevron visible (no hidden columns) | `overflow-x-auto` wrapping table; all 6 columns always shown |
| Desktop (≥ 640px) | As above | Full table without scroll wrapper (sufficient horizontal space) |

**Placement:** no changes to `src/app/page.tsx`. The extension lives entirely within `FixtureEaseRankingPanel.tsx` per CONTEXT D-05.
