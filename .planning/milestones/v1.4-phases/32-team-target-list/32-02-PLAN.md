## Top-3 player selection (per expanded team)

Helper function (place inside the component body, before the return — or as a module-level pure helper if preferred):

```typescript
function getTopPlayers(
  teamId: number,
  players: MergedPlayer[],
  xgiMap: Map<number, number>,
): MergedPlayer[] {
  return players
    .filter((p) => p.team === teamId && p.status === 'a')
    .sort((a, b) => (xgiMap.get(b.id) ?? 0) - (xgiMap.get(a.id) ?? 0))
    .slice(0, 3)
}
```

Filtering by `status === 'a'` enforces CONTEXT D-06 ("Limited to status === 'a' players"). Sorting uses `xgiMap.get(p.id) ?? 0` so players absent from the map (zero-division-guarded teams) sort last but are still included up to the slice(3) limit. The slice(0,3) takes top 3 by descending xGI%.
