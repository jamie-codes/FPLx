## v1 Requirements

### Monte Carlo Display

- [ ] **MC-01**: User can see haul %, blank %, P10 pts, and P90 pts for any player in the xPts hover card via an `MCDistributionBar` component — requires `mc_enabled` gate activation in `accuracy_backtest.json`, `MC_ITERATIONS=10000` and `MC_SEED=42` in GitHub Actions env block, and workflow hygiene fixes (align `anthropic` Python pin to 0.98.1, add explicit numpy 2.2.3)
- [ ] **MC-02**: User can see P10/P90 pts range on the captain picks card to support Triple Captain and differential captaincy decisions

### Calibration

- [x] **CAL-01**: GK/DEF calibration position tab no longer shows misleading miscalibration signals caused by sparse data — sparse-bucket threshold raised from `sample_n < 5` to `sample_n < 15` for GK/DEF and `sample_n < 8` for MID/FWD in `pipeline/accuracy.py`; chart hidden entirely if position pool total < 50 observations
- [x] **CAL-02**: User can see a one-sentence calibration health summary on the Decision Summary tab, derived from existing `useAccuracy` data (no new fetch or pipeline work)

### Sensitivity & Rejection Explainer

- [x] **SENS-01**: User can see a fragility indicator on each transfer buy candidate in TransferPanel — robust = silent (no badge), fragile = small amber dot, knife_edge = amber pill — computed by `computeFragility` with `isTransfer: true` context
- [x] **WHY-01**: User can expand a transfer sell candidate in TransferPanel to see the top-2 plain-English reasons why that player fell below the recommendation threshold (e.g. "xPts 4.2 < threshold 4.7"), computed by the existing `computeRejection` engine

### Per-Player LLM Insights

- [ ] **NLP-02**: User can request an on-demand AI-generated insight for any player from GemTable row expand or TransferPanel via an explicit "Get AI insight" button; insight is generated by `claude-haiku-4-5-20251001` grounded in structured player data (MC fields, rejection reasons, fragility tier); result cached per `(player_id, pipeline_run_date)` in localStorage and Vercel Blob (`player_insights/gw{N}/element_{id}.json`); never auto-generated on row mount; includes two-attempt name-whitelist guardrail with deterministic fallback to structured `reasons[]`

## Out of Scope

- MC simulation in browser TypeScript — 700 players × Math.random() loops freeze the main thread; pipeline is authoritative
- Prompt caching for v1.18 — NLP-02 system prompt is ~80 tokens, well below the 1024-token cache minimum
- Auto-generation of per-player insights on GemTable row mount — cost explosion risk (~$16–32/season from single bug)
- Push notifications or email alerts
- Real-time within-GW updates
